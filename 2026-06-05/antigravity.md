- 중복 보고 방지 상태: `.version`이 비어 있었기 때문에 이번 내용을 최초 기준으로 저장했습니다.

## GUI App

### Antigravity IDE `2.0.1` (2026-05-19)

- Antigravity 2.0 출시 직후 버그 수정 릴리스입니다.
- CJK 문자가 들어간 프로젝트 제목에서 마이그레이션 문제가 생기던 버그가 수정됐습니다.
- Antigravity 1.0에서 가져올 때 프로젝트가 중복 생성되던 문제가 수정됐습니다.
- Google One 크레딧이 적용되거나 사용되지 않던 문제가 해결됐습니다.
- 쉽게 말하면, 2.0으로 넘어가는 과정에서 프로젝트 이전과 결제/크레딧 적용이 꼬이던 문제를 고친 업데이트입니다.

## CLI App

- Antigravity CLI는 Antigravity 2.0의 터미널 중심 인터페이스로 소개되어 있습니다.
- 오늘 확인한 changelog 최신 항목은 IDE `2.0.1` 버그 수정이며, CLI만의 별도 버전 변경사항은 확인되지 않았습니다.
- CLI 제품 설명 기준으로는 자연어 작업, 병렬 서브에이전트, `/agents`, `/config`, `/keybindings`, slash commands, 플러그인/MCP/스킬/훅 구성이 핵심 기능으로 안내됩니다.
- 쉽게 말하면, CLI는 2.0 플랫폼의 가벼운 터미널 입구이고, 이번 중복 방지 기준은 공식 changelog의 IDE `2.0.1`에 맞춰 저장했습니다.
