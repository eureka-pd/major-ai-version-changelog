# Claude Code

- 중복 보고 방지 상태: `.version`이 비어 있었기 때문에 이번 내용을 최초 기준으로 저장했습니다.
- 출처: [Claude Code CHANGELOG](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md)

## GUI App

Claude Code의 데스크톱/IDE 쪽 변경도 같은 `2.1.x` 릴리스 노트에 함께 포함됩니다.

- 최신 `2.1.165`는 공개 설명이 짧고, 버그 수정과 안정성 개선으로 요약되어 있습니다.
- 직전 상세 릴리스인 `2.1.163`에서는 백그라운드 작업 칩의 Stop 동작, 패널 닫힘 뒤 남는 이상한 표시, 터미널 정렬과 멈춤 현상 같은 화면/상호작용 문제가 많이 고쳐졌습니다.
- 쉽게 말하면, 새 기능을 크게 추가했다기보다 앱이 덜 멈추고, 표시가 덜 깨지고, 백그라운드 작업을 더 안정적으로 다루게 된 업데이트입니다.

## CLI App

- 최신 `2.1.165`는 버그 수정과 안정성 개선입니다.
- `2.1.163`에서는 조직 관리자가 허용 버전 범위를 강제할 수 있는 설정이 추가됐습니다. 회사에서 승인하지 않은 버전이면 Claude Code가 시작되지 않도록 막을 수 있습니다.
- `/plugin list` 명령이 추가되어 설치된 플러그인을 켜짐/꺼짐 상태별로 확인할 수 있습니다.
- `claude -p`, Bedrock/Vertex/Foundry 인증, Windows/OneDrive 경로, Bash 임시 디렉터리, hooks 조건식, resume 동작 등 CLI 운영 중 자주 만날 수 있는 오류가 다수 수정됐습니다.
- 쉽게 말하면, 팀 관리 기능이 강화됐고 CLI가 여러 환경에서 덜 끊기도록 다듬어진 릴리스입니다.
