## GUI App

### Cursor `3.7` (2026-06-04)

- 캔버스에 디자인 모드가 추가됐습니다. 화면에서 UI 요소를 직접 선택하고 표시를 남겨 Cursor에게 수정 지시를 줄 수 있습니다.
- 컨텍스트 사용량 보고서가 캔버스로 제공됩니다. 시스템 프롬프트, 도구 정의, 규칙, 스킬 등에 토큰이 얼마나 쓰이는지 볼 수 있습니다.
- 공유된 캔버스를 브라우저 전체 화면으로 열 수 있게 됐습니다.
- 에이전트가 클릭하면 특정 프롬프트를 실행하는 버튼을 캔버스에 넣을 수 있습니다.
- 캔버스 타입 오류 수정, 컴포넌트 스타일링, 차트 커스터마이징이 개선됐습니다.
- 쉽게 말하면, Cursor가 만든 결과물을 눈으로 찍어 고치게 하고, 에이전트가 컨텍스트를 어디에 쓰는지도 더 쉽게 볼 수 있게 된 업데이트입니다.

## CLI App

- 이번 `3.7` changelog에는 CLI 전용 새 버전 변경사항은 따로 보이지 않았습니다.
- 최신 변화는 캔버스와 에이전트 작업 결과물을 다루는 GUI/제품 경험에 집중되어 있습니다.
