# Antigravity

- 확인 결과: 기존 `.version`의 Antigravity IDE `2.0.1` 기준보다 최신 항목이 있습니다.
- 중복 보고 방지 상태: `.version`을 Antigravity 2.0 `2.0.10`, Antigravity IDE `2.0.3`, CLI `2.0` 구성으로 갱신했습니다.
- 출처: [Google Antigravity changelog](https://antigravity.google/changelog), [Google Antigravity releases](https://antigravity.google/releases?hl=en)

## GUI App

### Antigravity 2.0 `2.0.10` (2026-05-28)

- AGY 2.0 버그 수정 릴리스입니다.
- 신뢰성과 사용성을 전반적으로 개선했고, Google One 크레딧 관련 버그를 고쳤습니다.
- 쉽게 말하면, 2.0 앱을 쓰다가 불안정하거나 크레딧이 제대로 반영되지 않던 문제를 다듬은 업데이트입니다.

### Antigravity 2.0 `2.0.6` (2026-05-22)

- Antigravity IDE 연동이 추가됐습니다.
- IDE가 없으면 설치 버튼을 보여주고, IDE가 있으면 현재 프로젝트를 IDE에서 열 수 있는 버튼을 제공합니다.
- 쉽게 말하면, 2.0 관리 앱에서 코드 편집용 IDE로 넘어가는 길이 더 쉬워졌습니다.

### Antigravity IDE `2.0.3`

- 공식 releases 페이지 기준으로 Antigravity IDE 최신 다운로드 버전은 `2.0.3`입니다.
- 쉽게 말하면, IDE 자체는 `2.0.1`보다 최신 빌드가 올라와 있으므로 오늘부터 별도 구성 버전으로 추적합니다.

## CLI App

- Antigravity CLI는 Antigravity 2.0 제품군의 터미널 중심 인터페이스로 안내됩니다.
- 오늘 확인한 changelog에는 CLI만의 별도 패치 번호가 보이지 않아 `2.0` 제품군 기준으로 저장했습니다.
- 쉽게 말하면, CLI는 2.0 플랫폼을 터미널에서 쓰는 입구이고, 이번 새 내용은 앱/IDE 연동과 안정화 쪽이 중심입니다.
