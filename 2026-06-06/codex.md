## GUI App

### Codex app `26.602` (2026-06-04)

- 새 GUI 앱 버전은 없습니다.
- 기존 최신 항목은 프로필 활동 인사이트, 공유 카드, Computer Use 시작 준비 개선, appshot 오류 보고 개선, 브라우저/리뷰/터미널 UI 수정입니다.
- 쉽게 말하면, 앱 안에서 사용 현황을 보기 쉬워졌고 화면과 시작 안정성이 좋아진 업데이트가 계속 최신입니다.

## CLI App

### Codex CLI `0.137.0` (2026-06-04)

- TUI에서 F13-F24 키 설정, 검색 메뉴 붙여넣기, 추론 전용 상태 표시가 추가됐습니다.
- 엔터프라이즈/관리 흐름에서 월간 크레딧 제한과 클라우드 관리 설정 번들 적용이 보강됐습니다.
- 원격 제어, 플러그인 목록 JSON 출력, 웹/이미지 도구, 멀티 에이전트 v2 관련 기능이 개선됐습니다.
- 프롬프트 취소, 슬래시 명령 UI, macOS/Windows 실행 안정성, 플러그인 로딩, 권한 승인, 로컬 세션 기록 관련 버그가 고쳐졌습니다.
- 쉽게 말하면, 터미널 Codex가 더 많은 단축키와 관리 기능을 갖추고, 플러그인/권한/세션 쪽에서 덜 깨지도록 정리된 릴리스입니다.
