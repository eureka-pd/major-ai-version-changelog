## GUI App

### Cursor `3.7` (2026-06-05)

- 디자인 모드가 Cursor 브라우저에서 더 좋아졌습니다.
- 브라우저 화면에서 여러 UI 요소를 동시에 선택할 수 있습니다. 그러면 에이전트가 선택한 요소, 코드, 주변 레이아웃, 요소 간 시각 관계를 함께 이해합니다.

- 쉽게 말하면, 화면에서 여러 곳을 찍고 말로 설명하면서 UI 수정을 더 빠르게 맡길 수 있게 된 업데이트입니다.
