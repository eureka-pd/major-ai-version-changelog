## GUI App

### Antigravity 2.0 `2.0.11` (2026-06-03)

- 특정 antivirus 제품이 설치된 환경에서 앱 시작 시 어두운 빈 화면이 뜨는 문제가 수정됐습니다.
- Open IDE 버튼과 관련된 일부 버그가 수정됐습니다.
- 쉽게 말하면, 앱이 처음 켜질 때 빈 화면으로 멈추는 문제와 IDE 열기 버튼 문제를 고친 안정화 업데이트입니다.

### Antigravity IDE `2.0.4` (2026-06-02)

- IDE 최신 기준은 계속 `2.0.4`입니다.
- Enterprise 계정 인증의 빈 화면 수정은 이미 이전 보고서에 반영되어 있습니다.
- 쉽게 말하면, 오늘 새 보고 대상은 IDE가 아니라 Antigravity 2.0 본체입니다.

## CLI App

- Antigravity CLI는 여전히 `2.0` 제품군 기준으로 추적합니다.
- 오늘 확인한 changelog에는 CLI만의 별도 패치 번호가 보이지 않았습니다.
- 쉽게 말하면, CLI는 새 패치 번호가 따로 보이지 않고, 이번 업데이트의 중심은 GUI 본체 안정성입니다.
