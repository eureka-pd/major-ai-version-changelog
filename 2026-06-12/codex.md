## GUI App

### Codex app `26.608` (2026-06-09)

- Claude Code와 Claude Cowork에서 지원되는 설정을 Codex로 가져오는 migration flow가 추가되었습니다. 처음 시작할 때 기존 환경을 옮기기 쉬워졌습니다.
- plugins 화면이 탭, marketplace, category filter, keyboard navigation 중심으로 개편되었습니다. plugin을 찾고 설치하는 흐름이 더 명확해졌습니다.
- Settings 검색 범위가 넓어져 Git, pets 같은 더 많은 설정 항목을 찾을 수 있습니다.
- 좁은 화면에서 goal timer가 겹치던 문제가 수정되었습니다.
- goal이 계속 실행 중일 때 unread notification이 과하게 쌓이는 문제가 줄었습니다.
- review diff 순서가 file tree와 더 일관되게 맞춰졌습니다.
- Windows 10처럼 translucent backdrop을 지원하지 않는 환경의 window rendering이 개선되었습니다.
