## GUI App

### Antigravity 2.0 `2.1.4` (2026-06-11)

- Quota screen이 바뀌어 Models tab에서 사용한 credit과 남은 credit을 더 명확하게 구분해 볼 수 있습니다.
- `/btw` slash command가 추가되었습니다. 현재 대화 context를 가진 임시 single-response agent에게 옆질문을 보낼 수 있습니다.
- 대화 화면에서 `Cmd`+`F` 또는 `Ctrl`+`F`로 보이는 텍스트를 검색할 수 있습니다.
- Gemini models에 PDF 파일을 message attachment로 넣을 수 있습니다.
- file viewer pane header에 breadcrumbs가 추가되어 repo directory 위치를 더 쉽게 보고 이동할 수 있습니다.
- overview pane에서 한 단계 아래 subagent만 보이던 제한이 줄어, nested subagents까지 볼 수 있습니다.
- Project 생성 시 project name을 지정할 수 있고, 왼쪽 sidebar conversation을 worktree 기준으로 정렬할 수 있습니다.
- LaTeX 출력 이해, MCP server 안정성, Chrome DevTools MCP server 사용 시 browser agent self-troubleshooting, `mcp_config.json` schema의 `url` field 호환성, `.vscode`와 `.cache` sensitive path 인식이 개선되었습니다.
