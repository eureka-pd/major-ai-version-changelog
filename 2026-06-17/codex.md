# Codex

오늘 Codex에서는 두 가지를 반영했습니다. Codex CLI 안정 버전은 `0.139.0`에서 `0.140.0`으로 올라갔고, Codex app은 버전 번호 변경 없이 2026-06-16 지역 제공 범위 공지가 새로 추가됐습니다.

## GUI App

- 최신 앱 버전 저장 기준: `26.609`
- 새 앱 버전 번호는 아직 없습니다.
- 2026-06-16 공식 changelog에는 EEA, UK, Switzerland 사용자에게 더 많은 Codex app 기능이 제공된다는 공지가 추가됐습니다.
- 핵심 내용은 Computer Use, Codex Chrome extension, Memories, Chronicle 제공 범위입니다.
- Computer Use는 해당 지역에서 데스크톱 앱을 보고 클릭하고 입력하는 작업에 사용할 수 있게 됐습니다.
- Codex Chrome extension은 로그인된 Chrome 상태가 필요한 브라우저 작업에 쓸 수 있습니다.
- Memories는 선호사항, 반복 워크플로, 기술 스택, 저장소 규칙을 기억할 수 있지만, EEA/UK/Switzerland에서는 기본값이 꺼져 있습니다.
- Chronicle은 macOS의 ChatGPT Pro 사용자를 위한 opt-in research preview로 제공됩니다.

## CLI App

- 최신 저장 기준: `0.140.0`
- npm `@openai/codex`의 `latest` 태그가 `0.140.0`으로 올라갔습니다.
- 공식 Codex changelog에는 `0.140.0` CLI 상세 항목이 아직 별도로 보이지 않습니다. 따라서 이번 문서에는 npm 안정 버전 상승만 기록했습니다.
- npm `alpha` 태그는 `0.141.0-alpha.3`입니다. pre-release이므로 안정 버전 보고 대상에는 넣지 않았습니다.

## Mobile

- 최신 저장 기준: ChatGPT for iOS `1.2026.153`
- 오늘 확인한 공식 changelog에서 모바일 새 버전 번호는 보이지 않았습니다.
- 기존 2026-06-09 항목이 최신 모바일 기준입니다.
