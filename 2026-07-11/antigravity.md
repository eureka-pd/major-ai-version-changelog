# Antigravity

오늘 새로 반영할 Antigravity 버전은 없습니다. 공개 changelog와 release API에서 확인되는 최신 기준은 Antigravity 2.0 `2.2.1`, Antigravity IDE `2.1.1`입니다.

## GUI App

- 최신 저장 기준은 계속 Antigravity 2.0 `2.2.1`입니다.
- 공개 download bundle과 Hub release API 모두 `2.2.1`을 최신 버전으로 제공합니다.
- 저장된 기준 이후 `2.2.2` 이상의 새 GUI release는 확인되지 않았습니다.

## IDE App

- 최신 저장 기준은 계속 Antigravity IDE `2.1.1`입니다.
- IDE release API의 최신 항목도 `2.1.1`이며, 새 `2.1.2` 이상 버전은 확인되지 않았습니다.

## CLI App

- Antigravity 2.0 제품군의 CLI baseline은 계속 `2.0`으로 유지합니다.
- 공식 changelog에서 별도 새 CLI patch version은 확인되지 않았습니다.
