# Antigravity

오늘 새로 반영할 Antigravity 버전은 없습니다. 공개 changelog와 release API의 최신 기준은 Antigravity 2.0 `2.2.1`, Antigravity IDE `2.1.1`입니다.

## GUI App

- 최신 저장 기준은 계속 Antigravity 2.0 `2.2.1`입니다.
- Hub release API에서도 `2.2.1`이 최신이며 새 GUI release는 확인되지 않았습니다.

## IDE App

- 최신 저장 기준은 계속 Antigravity IDE `2.1.1`입니다.
- IDE release API에서도 `2.1.1`이 최신이며 새 IDE release는 확인되지 않았습니다.

## CLI App

- `.version`의 `2.0`은 Antigravity 2.0 제품군 기준으로 유지합니다.
- 설치 manifest의 binary version은 별도 체계인 `1.1.1`이며, 공개 changelog에 새 CLI release 항목은 없습니다.
