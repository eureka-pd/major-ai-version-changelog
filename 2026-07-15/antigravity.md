# Antigravity

오늘 Hub와 IDE의 새 release는 없지만, 설치 manifest의 CLI binary가 `1.1.1`에서 `1.1.2`로 바뀌었습니다. 제품군 기준 `2.0`과 설치 binary 버전은 서로 다른 체계로 관리합니다.

## GUI App

- 최신 저장 기준은 계속 Antigravity 2.0 `2.2.1`입니다.
- Hub release API에서도 `2.2.1`이 최신이며 새 GUI release는 확인되지 않았습니다.

## IDE App

- 최신 저장 기준은 계속 Antigravity IDE `2.1.1`입니다.
- IDE release API에서도 `2.1.1`이 최신이며 새 IDE release는 확인되지 않았습니다.

## CLI App

- `.version`의 제품군 기준은 계속 `2.0`으로 유지합니다.
- 설치 manifest의 별도 binary version을 `1.1.1`에서 `1.1.2`로 올렸습니다.
- 공개 changelog에는 이 binary의 세부 변경 설명이 없어, 새 기능이나 수정 내용을 추정하지 않았습니다.
