# Codex

오늘 새로 반영할 Codex 안정 버전은 없습니다. Codex CLI 안정판은 `0.144.4` 그대로이며, 사전 공개 테스트 빌드만 `0.145.0-alpha.13`으로 올라갔습니다.

## GUI App

- 숫자로 공개된 최신 Codex 앱 버전 저장 기준은 계속 `26.616`입니다.
- 2026-07-09 ChatGPT desktop app 통합 이후 새 GUI release 항목은 확인되지 않았습니다.

## CLI App

- 안정 버전 최신 기준은 계속 `0.144.4`입니다.
- 공식 changelog에서 저장 기준 이후 새 안정판은 확인되지 않았습니다.
- 사전 공개 테스트 빌드를 `0.145.0-alpha.11`에서 `0.145.0-alpha.13`으로 올렸습니다.
- alpha 빌드는 안정판이 아니며 세부 변경 설명도 공개 changelog에 없으므로, `.version`에서 stable과 분리해 추적합니다.

## Mobile

- 최신 저장 기준은 계속 ChatGPT for iOS `1.2026.188`입니다.
- 저장된 기준 이후 새 mobile release 항목은 확인되지 않았습니다.
