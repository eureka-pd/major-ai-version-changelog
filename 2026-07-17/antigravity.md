# Antigravity

오늘 새로 반영할 항목은 Antigravity CLI 설치 manifest의 binary version `1.1.3`입니다. GUI와 IDE의 공개 버전은 그대로이며, CLI binary에는 별도 변경 설명이 공개되지 않았습니다.

## GUI App

- 최신 저장 기준은 계속 Antigravity 2.0 `2.3.0`입니다.
- 공개 changelog와 Hub release API에서 새 GUI release는 확인되지 않았습니다.

## IDE App

- 최신 저장 기준은 계속 Antigravity IDE `2.1.1`입니다.
- IDE release API에서 새 IDE release는 확인되지 않았습니다.

## CLI App

- 제품군 기준은 계속 `2.0`입니다.
- 설치 manifest의 별도 binary version을 `1.1.2`에서 `1.1.3`으로 올렸습니다.
- 새 binary가 배포됐지만 공개 changelog에는 CLI 전용 변경 설명이 없어 버전만 기록합니다.
