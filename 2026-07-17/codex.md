# Codex

오늘 새로 반영할 Codex 안정 버전은 CLI `0.144.5`입니다. 위험한 삭제 명령을 더 정확히 막도록 보완됐고, 사전 공개 테스트 빌드는 별도로 `0.145.0-alpha.18`까지 올라갔습니다.

## GUI App

- 숫자로 공개된 최신 Codex 앱 버전 저장 기준은 계속 `26.616`입니다.
- 저장된 기준 이후 새 GUI release 항목은 확인되지 않았습니다.

## CLI App

- 안정 버전 최신 기준을 `0.144.4`에서 `0.144.5`로 올렸습니다.
- `rm`을 강제로 실행하는 여러 형태를 포함해 위험 명령 감지 범위를 넓혔습니다.
- 명령이 거부됐을 때 그 이유를 더 분명하게 보여줍니다.
- 사전 공개 테스트 빌드는 `0.145.0-alpha.13`에서 `0.145.0-alpha.18`로 올라갔습니다.
- alpha 빌드는 안정판이 아니며 세부 변경 설명도 공개 changelog에 없으므로 `.version`에서 stable과 분리해 추적합니다.

## Mobile

- 최신 저장 기준은 계속 ChatGPT for iOS `1.2026.188`입니다.
- 저장된 기준 이후 새 mobile release 항목은 확인되지 않았습니다.
