# Cursor

## GUI App

- 최신 버전 번호는 계속 Cursor `3.11`입니다.
- 7월 17일에 Slack 연동 개선 사항이 새 changelog로 공개됐습니다.
- Slack에서 작업을 시작하기 전에 계획을 보여 주고, 진행 중에는 상태를 계속 알려 줍니다.
- frontend, backend처럼 여러 repo가 나뉜 프로젝트에서 알맞은 repo 환경을 고르고, 작업 중에도 다른 repo로 전환할 수 있습니다.
- 다른 Slack 채널과 thread의 내용을 읽어 context로 쓰고, 원래 thread나 관련 채널에 진행 상황을 보낼 수 있습니다.
- 응답의 버튼을 간단한 footer link로 바꾸고 표, PR, artifact 표시를 정리했습니다.

## CLI App

- CLI 전용 새 안정 버전 번호는 확인되지 않았습니다.
- `.version`의 CLI 값은 계속 `null`입니다.
