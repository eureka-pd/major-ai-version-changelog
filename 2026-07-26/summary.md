# SUMMARY

## Claude Code

### GUI App

- Claude Code 공통 최신 기준이 `2.1.219`에서 `2.1.220`으로 올라갔습니다.
- GUI 전용으로 따로 구분된 추가 release는 확인되지 않았습니다.

### CLI App

- 이번 버전은 새 기능보다 오류 수정과 안정성 개선에 집중했습니다.

## Codex

### GUI App

- Codex Desktop이 `26.707`에서 `26.715`로 올라갔습니다.
- 데스크톱 앱에서 음성으로 작업을 시작하거나 다른 작업의 진행을 확인하고 방향을 조정할 수 있습니다.
- 하나의 로컬 프로젝트에 여러 폴더를 넣을 수 있으며, 주 폴더가 새 대화·Git 작업·`AGENTS.md` 및 설정 자동 탐색의 기준이 됩니다.

### CLI App

- 최신 안정 버전은 계속 `0.145.0`입니다. 새 CLI release는 확인되지 않았습니다.

### Mobile

- 최신 저장 기준은 ChatGPT for iOS `1.2026.195`입니다.
- 새 모바일 release는 확인되지 않았습니다.

## Cursor

### GUI App

- 최신 버전 번호는 계속 Cursor `3.11`입니다.
- 7월 22일 Cursor Router 공지 이후 새 changelog는 확인되지 않았습니다.

### CLI App

- CLI 전용 새 안정 버전 번호는 확인되지 않았습니다.

## Antigravity

### GUI App

- Antigravity 2.0의 공식 배포 버전이 `2.3.1`에서 `2.4.2`로 올라갔습니다.
- changelog 본문에는 아직 `2.3.1`까지만 설명되어 있어, `2.4.2`의 기능 변경 내용은 확인되지 않았습니다.

### IDE App

- 최신 저장 기준은 계속 Antigravity IDE `2.1.1`입니다.
- 새 IDE release는 확인되지 않았습니다.

### CLI App

- 제품군 기준은 계속 `2.0`입니다.
- macOS ARM용 공식 설치 binary가 `1.1.6`에서 `1.1.7`로 올라갔습니다.
- 공개 manifest에는 설치 파일과 무결성 검증용 SHA-512 값이 새 버전으로 갱신됐습니다.
