# Antigravity

## GUI App

- Antigravity 최신 버전은 `2.4.2`로 유지됩니다.
- 미리보기 탭, `.json`·`.md`·`.csv` 첨부, MCP 연결·도구 시간 제한을 추가한 7월 24일 릴리스 이후 새 버전은 확인되지 않았습니다.

## IDE App

- 최신 IDE 버전은 `2.1.1`로 유지됩니다.
- 새 IDE 전용 릴리스는 확인되지 않았습니다.

## CLI App

- CLI 공개 버전은 `2.0`으로 유지되고, 바이너리 버전이 `1.1.6`에서 `1.1.8`로 업데이트되었습니다.
- 자동화용 출력 형식으로 `json`과 `stream-json`을 추가하고, `--json-schema`로 최종 결과 형식을 검사할 수 있게 했습니다.
- 도구·하위 에이전트 정보와 캐시 토큰 사용량을 구조화된 출력에 포함하며, 복합 명령의 반복 권한 확인도 줄였습니다.
