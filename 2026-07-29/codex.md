# Codex

## GUI App

- Codex Desktop 최신 버전은 `26.715`로 유지됩니다.
- 음성 작업과 다중 폴더 로컬 프로젝트를 추가한 7월 23일 릴리스 이후 새 Desktop 릴리스는 확인되지 않았습니다.

## CLI App

- 최신 안정 CLI 버전은 `0.145.0`으로 유지됩니다.
- 대화 기록, 가져오기, Bedrock 로그인, 오디오 입력, 멀티 에이전트 기능을 확대한 7월 21일 릴리스 이후 새 CLI 릴리스는 확인되지 않았습니다.

## Mobile

- iOS Remote가 `1.2026.195`에서 `1.2026.202`로 업데이트되었습니다.
- 음성 대화에 선택한 ChatGPT 음성과 사용 한도 경고를 적용하고, 앱 복귀·Face ID 해제 뒤 작업 연결을 더 안정적으로 유지합니다.
- 플러그인 멘션과 설치된 스킬 자동완성을 데스크톱과 맞추고, 큰 워크스페이스 diff·시각화·작업 복원 관련 오류를 개선했습니다.
