# Cursor

## GUI App

- 최신 앱 버전은 `3.11`로 유지됩니다.
- 새 데스크톱 앱 버전은 없지만, 7월 28일 인도 전용 월 ₹649 `Cursor Start` 요금제가 추가되었습니다.
- 이 요금제에는 모델 사용량, 상시 실행 클라우드 에이전트, iOS 원격 제어, 플러그인·MCP·훅·스킬 사용이 포함됩니다.

## CLI App

- 독립 CLI 버전 번호는 공지되지 않았습니다.
- Cursor Start는 CLI 전용 릴리스가 아니라 인도 지역의 요금제 및 제품 접근성 확대 공지입니다.
