# SUMMARY

2026-07-29 확인 결과, Codex iOS와 Antigravity CLI에 새 버전이 있고 Cursor에는 새 지역 요금제 공지가 있습니다. Claude Code와 각 데스크톱 앱의 최신 버전은 기존 기준을 유지합니다.

## Claude Code

### GUI App

- 최신 공통 버전 `2.1.220` 유지. 새 GUI 전용 릴리스 없음.

### CLI App

- 최신 버전 `2.1.220` 유지. 새 CLI 릴리스 없음.

## Codex

### GUI App

- Codex Desktop `26.715` 유지. 새 Desktop 릴리스 없음.

### CLI App

- 안정 CLI `0.145.0` 유지. 새 CLI 릴리스 없음.

### Mobile

- iOS Remote가 `1.2026.202`로 업데이트됨. 음성 경험, 작업 재연결, 플러그인·스킬 자동완성, 큰 diff와 시각화의 안정성을 개선함.

## Cursor

### GUI App

- 앱 버전 `3.11` 유지. 인도 전용 월 ₹649 `Cursor Start` 요금제를 새로 공지함.

### CLI App

- 독립 CLI 버전은 공지되지 않음. Cursor Start는 CLI 릴리스가 아닌 지역 요금제 확대임.

## Antigravity

### GUI App

- 최신 버전 `2.4.2` 유지. 새 GUI 릴리스 없음.

### IDE App

- 최신 IDE 버전 `2.1.1` 유지. 새 IDE 전용 릴리스 없음.

### CLI App

- CLI `2.0` 유지, 바이너리는 `1.1.8`로 업데이트됨. 자동화에서 쓸 구조화된 JSON 출력과 JSON 스키마 검사를 추가함.
