# Codex

## GUI App

- Codex Desktop 최신 버전은 `26.715`로 유지됩니다.
- 이번 확인에서 새 Desktop 전용 릴리스는 확인되지 않았습니다.

## CLI App

- 안정 CLI가 `0.145.0`에서 `0.146.0`으로 업데이트되었습니다.
- 새 세션의 이름을 정하거나 중요한 대화를 고정하고, 사이드 대화를 닫지 않고 전환할 수 있습니다.
- 에이전트 플러그인과 워크스페이스 플러그인 배포를 지원하며, 대화 분기와 원격 Code Mode 연결도 추가했습니다.
- 프록시 환경, MCP 재연결, 대화 기록 보존, Windows 조작과 터미널 반응성을 개선했습니다.

## General

- 지원되는 플러그인과 협력 서비스에서 ChatGPT 계정으로 더 간단히 가입·로그인하는 베타 기능이 시작되었습니다.
- 실제 권한 요청은 서비스별로 별도 검토·승인해야 합니다.
