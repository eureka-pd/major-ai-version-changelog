# Cursor

## GUI App

- 데스크톱 최신 앱 버전은 `3.11`로 유지됩니다.
- iPad용 Cursor가 모든 유료 플랜에 추가되었습니다. 넓은 화면에서 여러 에이전트 대화를 함께 보고, 파일 diff를 검토할 수 있습니다.
- iPhone·iPad에서 PR 댓글·검사·승인과 검토자 변경을 처리하고, 받은편지함으로 진행 중인 작업과 검토 항목을 관리할 수 있습니다.
- Bitbucket·Azure DevOps 지원, 여러 PR 세션 열기, 앱 안에서 팀 전환 기능도 포함됩니다.

## CLI App

- 독립 CLI 버전 번호는 공지되지 않았습니다.
- 이번 공지는 데스크톱이나 CLI 버전 업데이트가 아니라 iPad용 앱 기능 출시입니다.
