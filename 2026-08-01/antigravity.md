# Antigravity

## GUI App

- Antigravity `2.4.3`이 새로 배포되었습니다.
- 파일을 임시 미리보기 탭으로 열어 빠르게 살펴본 뒤, 필요한 탭만 고정할 수 있습니다.
- 채팅에 JSON, Markdown, CSV 파일을 첨부할 수 있습니다.
- MCP 연결과 도구 호출에 시간 제한을 적용해, 응답하지 않는 서버 때문에 작업이 멈추는 일을 줄였습니다.
- 대화 전환·긴 목록 스크롤이 빨라졌고, 대화 기록의 읽지 않음 필터와 진단 파일 내려받기가 추가되었습니다.

## IDE App

- 최신 IDE 버전은 `2.1.1`로 유지됩니다.
- 새 IDE 전용 릴리스는 확인되지 않았습니다.

## CLI App

- CLI 공개 버전은 `2.0`, 바이너리 버전은 `1.1.8`로 유지됩니다.
- 기준선 이후 새 CLI 릴리스는 확인되지 않았습니다.
