# Codex

## GUI App

- Codex Desktop `26.727`이 새로 배포되었습니다.
- 브라우저 방문 기록을 주소창에서 다시 찾고, Chrome 탭·선택한 웹페이지 문구를 대화에 바로 가져올 수 있습니다.
- 여러 저장소를 하나의 프로젝트에서 함께 보고, 한 화면에서 변경사항을 검토할 수 있습니다.
- 생성 이미지의 크게 보기·Canvas 보기와 댓글 기반 수정이 추가되었습니다.
- 사이드바에 최근 대화와 확인이 필요한 작업을 모아 보는 Activity 보기가 생겼습니다.
