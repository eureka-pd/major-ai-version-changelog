# SUMMARY

2026-08-01 확인 결과, Codex Desktop `26.727`과 Antigravity `2.4.3`이 새로 배포되었습니다. Claude Code와 Cursor에는 기준선 이후 새 버전 또는 기능 공지가 없습니다.

## Claude Code

### GUI App

- 최신 공통 버전 `2.1.220` 유지. 새 GUI 전용 릴리스 없음.

### CLI App

- 최신 CLI 버전 `2.1.220` 유지. 새 CLI 릴리스 없음.

## Codex

### GUI App

- Codex Desktop `26.727` 배포.
- 브라우저 기록·Chrome 탭·선택 문구를 대화에 가져오고, 여러 저장소의 변경사항을 한 화면에서 검토할 수 있음.
- 생성 이미지의 크게 보기·Canvas 보기·댓글 기반 수정과 최근 작업용 Activity 보기가 추가됨.

### CLI App

- 안정 CLI `0.146.0` 유지. 새 CLI 릴리스 없음.

### General

- 새 Codex 관련 일반 공지 없음.

### Mobile

- iOS Remote `1.2026.202` 유지. 새 모바일 릴리스 없음.

## Cursor

### GUI App

- 데스크톱 `3.11` 유지. 새 앱 릴리스나 기능 공지 없음.

### CLI App

- 독립 CLI 버전은 공지되지 않음. 새 CLI 관련 공지 없음.

## Antigravity

### GUI App

- Antigravity `2.4.3` 배포.
- 임시 미리보기 탭, JSON·Markdown·CSV 첨부, MCP 시간 제한이 추가됨.
- 대화 전환과 긴 목록 스크롤을 개선하고 읽지 않은 대화 필터·진단 파일 내려받기를 제공함.

### IDE App

- 최신 IDE 버전 `2.1.1` 유지. 새 IDE 전용 릴리스 없음.

### CLI App

- CLI `2.0`, 바이너리 `1.1.8` 유지. 새 CLI 릴리스 없음.
