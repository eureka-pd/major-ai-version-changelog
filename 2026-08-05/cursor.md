# Cursor 변경사항

2026-08-05 확인 결과, 데스크톱 버전은 `3.11`로 유지되며 Google Workspace 플러그인 공지가 새로 추가되었습니다.

## GUI App

- Google Drive, Gmail, Google Calendar 플러그인을 설치하면 Cursor 안에서 파일과 메일, 일정을 읽고 작성하거나 관리할 수 있습니다.
- 즉, 코딩 작업에 필요한 문서·메일·일정 정보를 Cursor 밖으로 옮기지 않고 연결해 사용할 수 있습니다.

## CLI App

- 독립 CLI 버전은 공지되지 않았고, 새 CLI 관련 공지도 없습니다.
