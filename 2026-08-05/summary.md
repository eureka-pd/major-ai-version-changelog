# SUMMARY

2026-08-05 확인 결과, Claude Code `2.1.221`, Antigravity 앱 `2.5.0`과 CLI `1.1.10`, Cursor의 Google Workspace 플러그인 공지가 새로 확인되었습니다. Codex는 새 버전이나 공지가 없습니다.

## Claude Code

### GUI App

- VS Code 확장에 Focus view가 추가되어, 도구 실행 내역을 접고 실행 상태와 턴별 요약을 볼 수 있습니다.

### CLI App

- Linux와 WSL 샌드박스에서 자격 증명 파일을 가리는 `mode: "mask"` 옵션이 추가되었습니다.
- 플러그인 검사 시 Claude Desktop의 관리형 마켓플레이스에서 거부될 이름을 미리 경고합니다.

## Codex

### GUI App

- Codex Desktop `26.727` 유지. 새 GUI 릴리스 없음.

### CLI App

- 안정 CLI `0.146.0`, 시험판 CLI `0.147.0-alpha.4` 유지.

### General

- 새 일반 공지 없음.

### Mobile

- iOS Remote `1.2026.202` 유지. 새 모바일 릴리스 없음.

## Cursor

### GUI App

- Google Drive, Gmail, Google Calendar 플러그인을 통해 Cursor 안에서 파일·메일·일정을 읽고 작성하거나 관리할 수 있습니다.

### CLI App

- 독립 CLI 버전은 공지되지 않았고, 새 CLI 관련 공지도 없습니다.

## Antigravity

### GUI App

- `2.5.0`은 Gemini Enterprise 및 Workforce Identity Federation 로그인을 지원하고, 모델별 추론 강도와 프로젝트 탐색을 개선했습니다.
- 파일 뷰어 충돌, 빈 작업공간 시작 멈춤, OAuth 인증 등 안정성 문제를 수정했습니다.

### IDE App

- 최신 IDE 버전 `2.1.1` 유지. 새 IDE 전용 릴리스 없음.

### CLI App

- CLI `1.1.10`은 Gemini Enterprise·WIF·ADC 인증을 추가하고, `.git`의 샌드박스 접근을 읽기 전용으로 변경했습니다.
- `--model`/`--effort` 적용과 하위 에이전트 종료 관련 문제를 수정했습니다.
