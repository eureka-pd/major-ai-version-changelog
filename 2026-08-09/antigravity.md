# Antigravity 변경사항

기준: 2026-08-09

## GUI App

- 버전: `2.6.0`
- 긴 대화와 대화 목록을 훨씬 빠르게 열 수 있습니다.
- 자동화로 시작한 대화가 사이드바에서 사라지지 않고 예약 작업 목록에 표시됩니다.
- 훅과 하위 에이전트가 멈추거나 끝나지 않던 문제를 고쳤고, 관리자 도구 서버 정책도 시작 시 적용됩니다.
- 이미지·동영상 미리보기와 이미지 복사를 추가하고, 댓글·스크롤·고정 대화 등 화면 동작을 다듬었습니다.

## IDE App

- 버전: `2.1.1`
- 이전 기록 이후 새 IDE 버전은 확인되지 않았습니다.

## CLI App

- 버전: `2.0` (CLI), `1.1.11` (CLI Binary)
- 이전 기록 이후 새 CLI 또는 CLI Binary 버전은 확인되지 않았습니다.
