# Claude Code 변경사항

기준: 2026-08-09

## GUI App

- 버전: `2.1.226`
- `2.1.225`에서 긴 대화 재개, 다른 기기 세션 간 메시지, 원격 제어 화면의 안정성을 보완했습니다.
- 최신 `2.1.226`은 별도 기능 추가 없이 버그 수정과 안정성 개선을 담았습니다.

## CLI App

- 버전: `2.1.226`
- 사용량 한도 경고에 한도 종류, 초기화 시각, 운영자 안내를 더 명확히 표시합니다.
- 신뢰되지 않은 작업 폴더에서는 `claude agents`도 실행 전에 확인을 요구합니다.
- 장시간 토큰을 쓰는 무인 세션, macOS MCP OAuth, 세션 간 메시지 전달·재개에서 발생하던 인증 및 멈춤 문제를 수정했습니다.
