# Antigravity 변경사항

## GUI App

- 버전: `2.8.0` (이전: `2.7.1`, 2026-08-12 공개)
- 사이드바 폴더의 펼침·접힘 상태를 기억하고, 큰 명령 출력이 포함된 대화가 종료되지 않도록 표시·기록 크기를 제한했습니다.
- 코드 색상, 여러 줄 명령 레이아웃, Linux 메뉴, 설정 화면의 문제를 수정했습니다.

## IDE App

- 버전: `2.5.5` (이전: `2.1.1`, 2026-08-13 공개)
- Windows에서 이미지·미디어를 첨부하지 못하던 문제와 채팅 전송이 느리거나 멈추던 문제를 고쳤습니다.

## CLI App

- 제품 탭: `2.0`, 바이너리: `1.1.12` (이전 바이너리: `1.1.11`, 2026-08-11 공개)
- 아티팩트 제목 목차와 print 모드의 읽기 전용 명령·구조화된 출력 형식을 추가했습니다.
- 헤드리스 모드, 진단, 하위 에이전트 메시지, 쿼터 표시와 저장소 감지 문제를 수정했습니다.
- 공식 페이지는 점진 배포를 안내하므로 실제 업데이트 도달까지 며칠 걸릴 수 있습니다.
