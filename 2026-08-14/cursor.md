# Cursor 변경사항

## GUI App

- 버전: `3.11`
- 2026-08-13에 버전 번호 없는 새 기능 공지가 게시되었습니다. 클라우드 Agent가 사전에 준비된 환경에서 시작해, 첫 응답까지의 시간을 최대 3배 줄인다고 안내합니다.
- 빌드가 실패하면 마지막으로 성공한 환경을 계속 사용하며, 대시보드에서 빌드 상태·로그·커밋 SHA를 확인하고 수동 빌드와 디버깅을 할 수 있습니다.
- 공지에 새 GUI 버전 번호는 없으므로 버전 기준선은 유지합니다.

## CLI App

- Cursor는 공식 변경 로그에 독립 CLI 버전을 게시하지 않습니다.
- 이전 기록 이후 새 CLI 변경사항은 확인되지 않았습니다.
