# Antigravity 변경사항

## GUI App

- 버전: `2.8.1` (이전: `2.8.0`, 2026-08-13 공개)
- 에이전트에 메시지를 보낼 때 응답이 느려지거나 멈추던 문제를 수정했습니다.

## IDE App

- 버전: `2.5.5`
- 이전 기록 이후 새 IDE 버전은 확인되지 않았습니다.

## CLI App

- 제품 탭: `2.0`, 바이너리: `1.1.13` (이전 바이너리: `1.1.12`, 2026-08-14 공개)
- `GEMINI_API_KEY`로 로그인 없이 Gemini API를 직접 쓸 수 있고, 커스텀 에이전트가 백그라운드 작업을 관리할 수 있습니다.
- 아티팩트 목록 스크롤, `/codesearch` 대체 검색, 내장 ripgrep 캐시 검증을 보강했습니다.
- 대화 기록 잘림, SQLite DB 증가, 하위 에이전트 경로 검증 문제를 수정했습니다.
- 공식 페이지는 점진 배포를 안내하므로 실제 업데이트 도달까지 며칠 걸릴 수 있습니다.
