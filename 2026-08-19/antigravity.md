# Antigravity 변경사항

## GUI App

- 버전: `2.8.1`
- 이전 기록 이후 새 GUI 앱 버전은 확인되지 않았습니다.

## IDE App

- 버전: `2.5.5`
- 이전 기록 이후 새 IDE 버전은 확인되지 않았습니다.

## CLI App

- 제품 탭: `2.0`, 바이너리: `1.1.14` (이전 바이너리: `1.1.13`, 2026-08-18 공개)
- 엔터프라이즈 로그인 복귀 경로와 MCP OAuth 클라이언트 ID 메타데이터 문서를 추가했습니다.
- `/context`·`/usage`를 터미널 크기에 맞게 스크롤할 수 있고, 마크다운 에이전트는 `inheritCustomizations`로 스킬·규칙·플러그인 상속을 한곳에서 정합니다.
- 워크스페이스 밖 경로는 읽기만 허용되며, LSP 종료·하이퍼링크·아티팩트 승인·MCP 오류 격리·붙여넣기 문제를 수정했습니다.
- 공식 페이지는 점진 배포를 안내하므로 실제 업데이트 도달까지 며칠 걸릴 수 있습니다.
