# Antigravity 변경사항

## GUI App

- 버전: `2.9.1` (이전: `2.8.1`, 2026-08-13 공개)
- 시작·프로젝트 전환·긴 대화 로딩이 빨라졌고, 사이드바 최상위 섹션을 접을 수 있습니다.
- Customizations 설정을 다시 구성했고, 커스텀 에이전트는 `inheritCustomizations`로 기존 스킬·규칙·서브에이전트를 재사용합니다.
- WebP 첨부와 PowerShell·Zsh 구문 강조를 추가하고, 알림 토스트·댓글 미리보기·에이전트 Retry·MCP 로딩 문제를 고쳤습니다.

## IDE App

- 버전: `2.5.5`
- 이전 기록 이후 새 IDE 버전은 확인되지 않았습니다.

## CLI App

- 제품 탭: `2.0`, 바이너리: `1.1.17` (이전 바이너리: `1.1.14`, 2026-08-18 공개)
- 에이전트 실행 하네스를 한 경로로 모아 도구·훅·프롬프트 동작을 맞췄습니다.
- `mcp add`·`remove`·`list`·`enable`·`disable`로 `mcp_config.json`을 관리하고, print 모드에 `--input-format stream-json`을 추가했습니다.
- `@` 경로 완성, `/effort` Flash 모델, 슬래시 명령·Vim insert·Ogg MIME·WIF 토큰 갱신 문제를 수정했습니다.
- 공식 페이지는 점진 배포를 안내하므로 실제 업데이트 도달까지 며칠 걸릴 수 있습니다.
