# Cursor 변경사항

## GUI App

- 버전: `3.11`
- 2026-09-10에 버전 번호 없는 새 기능 공지가 게시되었습니다. **Cursor Projects**(베타)로 기능·마이그레이션·앱 전체처럼 큰 작업을 맡길 수 있습니다. 수개월 컨텍스트를 유지하고, 많은 하위 에이전트에 위임하며, 별도 프롬프트 없이 반복 작업을 이어갑니다.
- 왼쪽 내비게이션에서 들어가며, 코디네이터 에이전트는 직접 코드를 쓰지 않고 계획·위임·결과 수거만 합니다. 필요한 만큼 에이전트를 병렬로 띄웁니다.
- 클라우드 Agent 전용 컴퓨터에서 돌아가 노트북을 닫아도 멈추지 않고, 로컬 테스트가 필요하면 코디네이터가 로컬 에이전트를 띄웁니다.
- 프로젝트마다 클라우드·로컬 머신에 동기화되는 공유 컨텍스트 파일을 쌓아, 조사 결과·선호 작업 방식을 이후 에이전트가 재사용합니다.
- Slack 채널 감시·일정 실행·PR 추적 같은 Subscriptions로 신호에 따라 위임을 시작할 수 있습니다. 오늘부터 전원에게 순차 배포됩니다. 공지에 새 GUI 버전 번호는 없으므로 버전 기준선은 유지합니다.

## CLI App

- Cursor는 이 변경 로그에서 별도 CLI 버전을 게시하지 않습니다.
- 이전 기록 이후 새 CLI 공지는 확인되지 않았습니다.
