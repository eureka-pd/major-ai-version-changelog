# Codex 변경사항

## GUI App

- 버전: `26.908` (이전: `26.727`, 2026-09-11)
- ChatGPT 데스크톱(macOS·Windows) Pets 플로팅 컨트롤에서 Quick Chat을 입력해 Enter로 보냅니다. `@`로 컨텍스트, `$`로 스킬을 고르고, 벨로 스레드 진행을 본 뒤 스레드를 열어 전체 대화를 봅니다.
- Settings > Pets에서 동반자 또는 컨트롤만 표시할 수 있습니다. macOS는 Option+Space, Windows는 Win+Alt+P로 Quick Chat에 포커스하고, 같은 단축키를 다시 눌러도 Quick Chat을 유지합니다. Show pet 단축키는 Settings > Keyboard shortcuts에서 바꿀 수 있습니다.
- macOS에서는 플로팅 컨트롤로 appshot을 보낼 수 있고, Appshot destination을 Automatic으로 두면 메인 창을 뒤에 둔 채 보낼 수 있습니다.
- Windows에도 Appshots가 추가되었습니다. 양쪽 Alt로 맨 앞 앱 창을 ChatGPT와 공유한 뒤 질문하거나 할 일을 적습니다. appshot은 스크린샷과 해당 창의 가용 텍스트를 포함합니다.
- Sources에서 파일 열기·미리보기 불가 파일 다운로드, Codex Micro 키에 Insert text 할당, Pets 기본 크기 리셋·커스텀 pet 아트워크 새로고침 시 위치 유지, 채팅 전환 후 미완성 댓글 유지, dictation의 Main language 반영, 브라우저 탭 너비·스크롤 안정화를 넣거나 고쳤습니다.
