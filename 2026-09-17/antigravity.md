# Antigravity 변경사항

## GUI App

- 버전: `2.14.0` (이전: `2.13.0`, 2026-09-15)
- Enterprise·Business 계정에 사이드바 통합 터미널·Git 버전 관리를 열고, 긴 대화의 메모리·로딩을 줄였습니다.
- 매 메시지 커스터마이즈 파일 중복 스캔 제거, Settings/artifacts/terminals 탭 로딩, Scratch Files를 Artifacts·Review에서 제외, 대화 메뉴·커맨드 팔레트·권한 섹션 이름·새 대화 단축키·Vesper 테마를 손봤습니다.
- Settings/탭 빈 화면, rule 파일 읽기 크래시, 종료된 터미널 출력 메모리 누수, 재연결 후 수 초 멈춤, 끝난 서브에이전트 running 표시, 일시 오류로 세션 종료(약 12분 재시도), @-mention Tab 덮어쓰기·카테고리 좁히기, 문서 내 앵커 링크, 블록 수식 이스케이프 `$`, Drive 폴더 Open Preview, 쿼터 문구 잘림, 사이드 질문 버튼, 라이선스 화면, 개인 계정 재로그인, git hooks로 체크포인트 실패, 스크린 리더·Mermaid(Gantt/timeline) 문제를 고쳤습니다.
