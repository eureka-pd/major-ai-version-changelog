# Antigravity 변경사항

## GUI App

- 버전: `2.17.0` (이전: `2.15.1`)
- **2.17.0** (2026-09-22): `/plan`으로 코드를 쓰기 전에 계획을 읽고 수정할 수 있습니다. Agent 설정 이름은 Plan Review Policy로 바뀌었고, 규칙 전용 20,000토큰 예산·커스텀 에이전트 hooks·Save Video·프로젝트 설정 경로 `/.gemini/config.json` 이전 등이 포함됩니다.
- **2.16.0** (2026-09-22): Windows에서 WSL 연결, Word·Excel·PowerPoint 첨부, 실시간 서브에이전트 카드, 이미지 우클릭 복사·저장을 지원합니다.

- 버전: `2.5.5`
- 이전 기록 이후 새 IDE 버전은 확인되지 않았습니다.

## CLI App

- 제품 탭: `2.0`, 바이너리: `1.2.9` (이전: `1.2.6`)
- **1.2.9** (2026-09-23): 서브에이전트에 직접 메시지를 보내는 `@` 문법·Vim count multiplier·headless 생명주기·대화 DB 동시성 수정을 포함합니다.
- **1.2.8** (2026-09-22): 컨텍스트 compaction 예산 비례 배분·커스텀 모델 PDF/오디오 기본 지원·음성 받아쓰기 상한·메모리 누수 수정을 포함합니다.
- **1.2.7** (2026-09-19): 아티팩트 뷰어 Kitty 그래픽(수식·Mermaid)·ask_question 탐색·규칙 전용 20,000토큰 예산·재시도 백오프 상한 30초를 포함합니다.
