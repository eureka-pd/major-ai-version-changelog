# Antigravity 변경사항

## GUI App

- 버전: `2.18.1` (이전: `2.17.0`)
- **2.18.1** (2026-09-28): Customizations 탭·마켓플레이스에서 플러그인을 찾고 설치·관리할 수 있습니다. 아카이브된 대화만 보기·터미널 권한 요청 구문 강조·실행 중 터미널 단계 기본 접기·플러그인 슬래시 명령에 플러그인 이름 표시·생성 이미지를 턴 하단에 유지·rules/customizations 토큰 예산 분리·프로젝트 삭제·대화 핀(⌥⌘P / Alt+Shift+P) 등 사이드바·채팅 UX를 다듬었고, Google 로그인·긴 대화 스크롤·다크모드 복사·엔터프라이즈 로그인·프롬프트 편집·권한·worktree 아티팩트 분류 등도 고쳤습니다.

## CLI App

- 제품 탭: `2.0`, 바이너리: `1.2.11` (이전 바이너리: `1.2.9`)
- **1.2.11** (2026-09-25): `--effort`·`/effort`로 모델별 reasoning effort를 고를 수 있고, 설정 변수가 필요한 `~/.gemini/config/plugins` 플러그인은 비활성으로 시작됩니다. WezTerm·VS Code 터미널의 Mermaid/LaTeX ASCII 폴백, Copy on Select 꺼진 상태의 artifact 복사, Desktop App·headless·`--agent`에서의 프로젝트 custom agent 발견도 고쳤습니다. (중간에 **1.2.10** medium verbosity·artifact 사전 렌더·샌드박스·headless exit code 3 등도 있었습니다.)
