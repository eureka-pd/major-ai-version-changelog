# Antigravity 변경사항

## GUI App

- 버전: `2.19.1` (이전: `2.18.1`)
- **2.19.1** (2026-09-30): 메시지 입력창에서 하위 에이전트에 직접 메시지를 보낼 수 있습니다. 표·코드·다이어그램을 포함한 Markdown의 PDF 내보내기를 지원합니다.
- 실행 취소 시 대화만 되돌릴 수 있게 했으며, 사용자 정의 에이전트가 전역·프로젝트 규칙을 무시하던 문제를 수정했습니다.

## IDE App

- 버전: `2.5.5`
- 이전 기록 이후 새 IDE 버전은 확인되지 않았습니다.

## CLI App

- 제품 탭: `2.0`, 바이너리: `1.2.12` (이전 바이너리: `1.2.11`)
- **1.2.12** (2026-09-27): 전체 화면 스크롤 지연과 CPU 사용을 개선했습니다. Gemini API의 일일 할당량·지출 한도·선불 크레딧 소진 시 불필요한 재시도 없이 중단합니다.
- 긴 대화의 재개 성능, tmux 등의 터미널 제목, Vim 다국어 문자 처리·실행 취소 오류를 수정했습니다.
- CLI 바이너리는 9월 27일 공개된 릴리스로, 이전 기록에 빠져 있어 이번 점검에 반영했습니다. 오늘 출시된 것으로 집계하지 않습니다.
