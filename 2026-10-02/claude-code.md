# Claude Code 변경사항

## GUI App

- 버전: `2.1.287` (이전: `2.1.286`)
- **Claude Mods**를 추가해 플러그인이 더 깊은 동작을 바꿀 수 있게 했습니다. 내장 **You should know**는 보조 에이전트가 놓치기 쉬운 사항을 알려 줍니다. 자사 서비스 세션에서 텔레메트리가 켜져 있을 때 사용할 수 있습니다.
- **VS Code**: 실행 중인 명령·하위 에이전트를 백그라운드로 보내는 기능, 에이전트 맵 카드의 백그라운드 셸·Monitor 출력이 추가됐습니다. 클라우드 세션 중복 열기와 복원 시 중복 프로세스, 파일 링크·원격 호스트의 출력 열기 문제를 수정했습니다.
- **연결·파일 전달**: Remote Control 재연결 응답이 없으면 30초 후 다시 시도합니다. 클라우드 대화 압축 중 재시작으로 이전 대화가 사라지던 문제, MCP 호출 중복, macOS 잠자기로 원격 작업이 멈추던 문제를 수정했습니다. 원격 파일 전송의 일시적 실패는 한 번 재시도하고, 큰 이미지는 축소해서 전달합니다.
- 화면 읽기 프로그램의 입력 위치·변경 내용 안내를 보완하고, 동작 줄이기 설정에서 남아 있던 애니메이션을 수정했습니다.

## CLI App

- 버전: `2.1.287`
- GUI 항목의 공통 변경사항과 함께 다음 내용이 적용됩니다.
- **권한 보호**: 위험한 `rm`에 출력 리디렉션을 함께 쓰면 항상 확인해야 하는 보호가 빠지던 문제와, 이름이 `__proto__`인 MCP 도구에서 조직 권한 상한이 누락되던 문제를 수정했습니다. 저장소 심볼릭 링크를 거쳐 민감한 파일이나 작업 트리 밖에 쓰는 명령은 실제 목적지를 표시하고 사람의 확인을 기다립니다.
- **모델·도구**: Bedrock·Vertex·Foundry·Claude 앱 게이트웨이의 Opus 4.7 이상과 Fable은 기본 1M 컨텍스트를 사용합니다. MCP 2025-11-25 프로토콜의 URL 요청과 에이전트 이름·작업을 찾는 `n:<text>` 필터를 추가했습니다.
- **운영 시 주의**: OpenTelemetry `user_prompt` 이벤트에 `prompt`의 복사본인 `prompt_text`가 추가됐습니다. 프롬프트를 제외하거나 마스킹하는 수집 설정은 새 필드에도 동일하게 적용해야 합니다.
- 공식 릴리스 게시 시각: 2026-10-01 18:00 UTC (한국 시간 2026-10-02 03:00). CHANGELOG 자체에는 날짜가 기재되어 있지 않습니다.
