## Claude Code

### GUI App

- 버전: `2.1.287` (이전: `2.1.286`)
- Claude Mods와 놓치기 쉬운 사항을 알려 주는 내장 You should know가 추가됐습니다. You should know는 자사 서비스 세션에서 텔레메트리가 켜져 있어야 합니다.
- VS Code에서 실행 중인 명령·하위 에이전트를 백그라운드로 보낼 수 있습니다. 원격 연결·파일 전달·접근성도 개선됐습니다.

### CLI App

- 버전: `2.1.287`
- 위험한 삭제 명령과 MCP 조직 권한 보호를 수정했습니다. 일부 클라우드 공급자의 Opus 4.7 이상·Fable은 기본 1M 컨텍스트를 사용합니다.
- OpenTelemetry로 프롬프트를 수집·마스킹한다면 새 `prompt_text` 필드에도 기존 보호 설정을 적용해야 합니다.
