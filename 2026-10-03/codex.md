## CLI App

- 버전: `0.160.0` (이전: `0.159.3`, 공식 변경 로그 날짜: 2026-10-01)
- 오래된 작업을 키보드로 더 불러올 수 있고, 정책이 허용하면 프로젝트 밖에서도 기본 작업공간 설정으로 세션을 시작할 수 있습니다. 재개 시 저장된 권한을 복원합니다.
- 연결 복구 후 미전송 대기 메시지를 중복 없이 이어 보내도록 수정했습니다. 터미널 UI의 공급자·출력 설정과 세션 재개 기록도 바로잡았습니다.
- Guardian 검토에 이전 사용자 지시와 에이전트 인계 문맥을 활용하는 선택적 기능이 추가됐습니다.
- 준비 중인 하위 에이전트 환경을 유지하고 준비 실패를 전달합니다. Windows 샌드박스·백그라운드 창, SQLite 멈춤, 모델 목록 갱신 문제를 수정했습니다.
- 지원되는 Linux X11 터미널의 전체 화면에서 텍스트 선택·가운데 클릭 붙여넣기를 지원합니다. 플러그인 로딩과 로그 저장 공간 관리도 개선했습니다.
- GitHub 릴리스 게시 시각: 2026-10-01 20:19 UTC (한국 시간 2026-10-02 05:19). 이번 점검에서 새로 확인한 버전이며, 10월 3일 출시로 집계하지 않습니다.
