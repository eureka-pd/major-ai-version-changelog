# Claude Code 변경사항

기준일: 2026-10-04 (Asia/Seoul). 공식 변경 로그에 날짜가 표시되지 않아 출시일은 단정하지 않습니다.

## GUI App / CLI App

- 버전: `2.1.288` (이전 기록: `2.1.287`)
- Ctrl+C로 지운 입력 초안을 위쪽 화살표로 복원합니다. 붙여 넣은 텍스트와 이미지도 포함됩니다.
- 응답 도중 API 시간 초과가 발생했을 때 비대화형 세션과 하위 에이전트가 부분 응답에서 이어가도록 개선했습니다. 긴 대화의 자동 압축과 세션 재개 시 문맥·마지막 답변 누락도 수정했습니다.
- `/code-review --max-findings`로 검토 결과 수를 조절하고, 에이전트 목록에서 이름 검색과 그룹 이동을 지원합니다.
- 큰 응답이나 파싱 실패 때문에 MCP 도구가 두 번 실행되던 문제를 수정했습니다. 로그인 정보 저장 실패를 성공으로 표시하던 문제와 위험한 셸 삭제 명령·훅 실패에 대한 권한 검사도 보완했습니다.
- 기존 저장소의 GUI/CLI 공통 버전 표기를 유지했습니다. 개별 기능의 적용 범위는 공식 변경 로그를 따릅니다.
