# Claude Code 변경사항

기준일: 2026-10-05 (Asia/Seoul). 이전 기록 이후 새로 확인한 변경사항입니다.

## GUI App / CLI App

- 버전: `2.1.289` (이전 기록: `2.1.288`)
- 여러 명령을 묶어 실행하거나 환경변수를 앞에 붙였을 때 셸의 차단·승인 규칙이 빠지던 문제를 수정했습니다. IDE에서 심볼릭 링크로 전달한 파일에도 읽기 차단 규칙을 적용합니다.
- 복잡한 코드 조각을 표시할 때 터미널이나 공개 Artifact 페이지가 멈추던 문제를 수정했습니다. 플러그인의 화면 처리 오류 때문에 세션 전체가 종료되던 문제도 줄였습니다.
- 업그레이드 직후 설치한 Mods가 로드되지 않거나 로컬 플러그인의 오래된 내용이 표시되던 문제를 수정했습니다. 큰 파일을 플러그인 코드 창에서 여는 속도도 개선했습니다.
- VS Code에서 로그아웃이 더 자주 발생했을 가능성이 있는 `2.1.288`의 인증 상태 확인 변경을 되돌렸습니다.
- 플러그인에서 팀원을 시작하는 `agent.spawn`과 에이전트의 대기·유휴 상태 표시를 추가했습니다.
- 공식 CHANGELOG에는 출시일이 없으며, GitHub 릴리스 게시 시각은 2026-10-03 23:07 UTC (한국 시간 10월 4일 08:07)입니다. 이번 점검일을 출시일로 집계하지 않습니다.
- 기존 저장소의 GUI/CLI 공통 버전 표기를 유지했습니다. 개별 기능의 적용 범위는 공식 변경 로그를 따릅니다.
