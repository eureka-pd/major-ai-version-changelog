# Cursor 변경사항

기준일: 2026-10-05 (Asia/Seoul). 공식 변경 로그와 배포 페이지를 구분해 확인했습니다.

## GUI App

- 공식 다운로드 페이지에서 최신 데스크톱 버전 `3.22`를 새로 확인했습니다. 기존 저장 기준 `3.11`은 변경 로그에 버전 번호가 명시된 최신 항목입니다.
- `3.22`의 공개일과 개별 변경 내역은 확인되지 않았습니다. 다운로드 페이지의 릴리스 노트 링크도 전체 변경 로그로 연결되므로, 특정 기능을 `3.22`에 임의로 연결하지 않습니다.
- 변경 로그의 최신 공지는 2026-09-23 Rollouts·Security Review로 이전 기록과 같습니다. 버전 `3.11` 항목의 날짜 2026-07-10도 보존합니다.
- `3.22`는 이번 점검에서 새로 확인한 배포 버전이며, 오늘 출시됐다는 의미는 아닙니다.

## CLI App

- 변경 로그에 별도 CLI 버전이나 신규 공지는 확인되지 않았습니다.
- 공식 설치 스크립트가 배포 대상으로 지정한 식별자 `2026.10.01-e373342`를 새로 기록합니다. 문자열에 포함된 날짜를 정식 발표일로 해석하지 않으며, 해당 빌드의 기능 변경은 확인되지 않았습니다.
- 설치 스크립트는 읽기만 했으며 설치·실행하지 않았습니다.
- 기존 변경 로그 기준값과 날짜는 유지하고, 배포 페이지·설치 스크립트의 확인값은 별도 기록으로 보존합니다.
