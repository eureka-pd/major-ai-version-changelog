# Antigravity 변경사항

기준일: 2026-10-07 (Asia/Seoul). IDE 확장판의 최신 릴리스를 이번 점검부터 별도로 기록합니다.

## GUI App / IDE App

- GUI `2.19.1` (2026-09-30), 독립 실행형 IDE `2.5.5` (2026-08-13); 변경 없음.

## CLI App

- CLI 바이너리: `1.2.14` (2026-09-30); 변경 없음.
- 기존 상태 파일의 제품 구분 `cli: 2.0`은 보존합니다.

## IDE Extensions

### VS Code 1.7.0

- 공식 표시일: 2026-10-05.
- Windows에서 앱을 보고 있지 않을 때 데스크톱 알림을 받을 수 있습니다.
- 코드 변경 승인·거절을 되돌리거나 다시 적용하고, 나란히 비교하는 창에서 전체 변경을 승인·거절할 수 있습니다.
- Cloud Workstations·Cloud Shell의 대화형 로그인을 지원합니다.
- 자동 저장·파일 재열기 과정의 변경 비교 안정성과 인증서 관련 다운로드 오류를 수정했습니다.

### Visual Studio 1.0.261005.0

- 공식 표시일: 2026-10-05.
- 피드백을 보낼 때 Visual Studio 버전과 로컬 서버 진단 로그를 자동 첨부해 문제 파악을 돕습니다.
- 채팅에서 피드백 창이 열리지 않던 문제를 수정했습니다.

## 확인 기준

- 두 확장판은 공식 변경 로그의 IDE Extensions와 공식 다운로드 페이지에서 확인했습니다.
- 독립 실행형 IDE `2.5.5`와 구분해 상태 파일에 확장판별 버전·날짜를 추가했습니다. 오늘 출시분으로 집계하지 않습니다.
- 공식 날짜에는 시각·시간대가 없으며, 새 버전은 사용자별로 며칠에 걸쳐 배포될 수 있습니다.
