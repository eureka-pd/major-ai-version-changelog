# Claude Code 변경사항

기준일: 2026-10-07 (Asia/Seoul). 이전 기록 `2.1.289` 이후 확인한 안정 릴리스 3건입니다.

## GUI App / CLI App

- 최신 버전: `2.1.292`.
- 저장소의 GUI/CLI 공통 버전 표기를 유지하며, 이 번호는 Claude Code 패키지 기준입니다.

### 2.1.292

- 공식 공개: 2026-10-06 18:59:30 UTC, 한국 시간 2026-10-07 03:59:30.
- 플러그인 설치 시 마켓플레이스를 지정하고, 에이전트별 추론 노력과 과부하 재시도 대기 시간을 설정할 수 있습니다.
- 대화를 재개·분기·초기화한 뒤 예약 작업이 실행되지 않거나 재시작 후 `/loop`가 멈추는 문제를 수정했습니다. 단발 실행에서 백그라운드 작업이 너무 일찍 끝나는 문제도 고쳤습니다.
- 네트워크 경로·심볼릭 링크·조직 플러그인 정책·샌드박스 읽기 제한의 보안 문제를 수정했습니다. 허용하지 않은 파일이나 경로에 접근할 수 있는 틈을 줄이는 업데이트입니다.
- 클라우드 권한 승인·알림, 세션 복구, MCP 초기 연결과 긴 응답 표시를 개선했습니다.
- 로컬 stdio MCP의 기본 프로토콜 협상을 `2026-07-28`로 변경했습니다. 호환성 문제가 있는 서버는 공식 안내의 legacy 설정을 확인해야 합니다.

### 2.1.291

- 공식 공개: 2026-10-06 03:55:19 UTC, 한국 시간 2026-10-06 12:55:19.
- `2.1.290`에서 클라우드 세션의 권한 질문 응답이 유실되던 문제를 수정했습니다.
- 종료 시 세션의 마지막 메시지가 사라질 수 있던 문제를 수정했습니다.

### 2.1.290

- 공식 공개: 2026-10-05 23:33:17 UTC, 한국 시간 2026-10-06 08:33:17.
- 세션 이름 일부로 연결하거나 로그를 확인하고, 긴 웹 문서 결과를 이어 읽을 수 있도록 개선했습니다.
- 대화 압축·재개·백그라운드 전환 과정에서 예약 작업이 사라지거나 중복 실행되는 문제와 권한 검사 관련 보안 문제를 수정했습니다.
- 대화형 웹 검색 한도를 시간에 따라 보충하는 방식으로 변경했습니다. 기본 한도는 시간당 100회입니다.
- VS Code 메시지 시각이 기본 표시됩니다. 브라우저 통합은 프로젝트 설정에서 켤 수 없도록 바뀌었습니다.

## 확인 기준

- 공식 CHANGELOG 상단과 GitHub API의 최신 안정 릴리스가 모두 `2.1.292`입니다.
- 웹 최신 릴리스 캐시가 잠시 `2.1.291`을 표시해, 개별 릴리스와 API의 공개 시각·안정판 여부를 교차 확인했습니다.
- 상태 파일의 날짜는 최신 릴리스 공개 시각의 UTC 날짜입니다. 위 세 버전을 모두 10월 7일 출시로 해석하지 않습니다.
