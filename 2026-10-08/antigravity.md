# Antigravity 변경사항

기준일: 2026-10-08 (Asia/Seoul). GUI 릴리스 1건을 새로 확인했습니다.

## GUI App

### 2.21.0

- 이전 기록: `2.19.1`. 공식 표시일: 2026-10-06.
- 대화 내용으로 검색하는 고급 검색을 추가했습니다.
- 예약 작업을 Automations로 통합했습니다. 즉시 실행하거나 에이전트와 대화하며 새 자동화를 설정할 수 있습니다.
- 파일 편집·터미널 명령·파일 읽기를 접을 수 있는 한 줄로 묶어 진행 내용을 확인하기 편해졌습니다.
- 손상된 동영상 이후 대화가 실패하던 문제, Windows 설정 파일 인식, 잘못된 모델 표시, 문서 첨부 표시를 수정했습니다.
- 공식 표시일은 10월 6일이며, 오늘 출시분이 아닌 이번 점검에서 처음 기록한 항목입니다.

## IDE App

- 독립 실행형 IDE `2.5.5` (2026-08-13); 변경 없음.

## CLI App

## IDE Extensions

- VS Code `1.7.0`, Visual Studio `1.0.261005.0` (각 2026-10-05); 변경 없음.

## 확인 기준

- 공식 변경 로그의 구성요소별 최신 항목을 비교했습니다.
- 공식 날짜에는 시각·시간대가 없으며 배포는 사용자별로 며칠 걸릴 수 있습니다.
