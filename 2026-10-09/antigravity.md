# Antigravity 변경사항

기준일: 2026-10-09 (Asia/Seoul). GUI 1건과 CLI 5건을 처음 기록합니다. 과거 출시분을 포함하며 오늘 출시된 버전이라는 뜻은 아닙니다.

## GUI App

### 2.21.1

- 이전 기록: `2.21.0`. 공식 표시일: 2026-10-07.
- 공식 최신 항목의 번호가 변경됐습니다. 검색·Automations 등 전날 기록과 겹치는 내용은 새 기능으로 재집계하지 않습니다.
- 공식 페이지에 2.21.0 대비 독립적인 패치 차이는 구분되어 있지 않습니다.

## CLI App

이전 기록 `1.2.14` 이후 공식 항목:

- `1.2.15` (10월 2일): Android Termux용 바이너리, 메모리 사용·SSH·사용량 제한 처리 개선.
- `1.2.16` (10월 3일): 설정값 전환, 텍스트 선택, 이미지 생성 전담 에이전트 및 백그라운드 작업 안정성 개선.
- `1.2.17` (10월 5일): 공지 카드, 관리자 권한 없는 Windows 샌드박스, 표 정렬 수정.
- `1.3.0` (10월 6일): 기본 출력 상세도가 medium으로 변경됩니다. 전체 표시가 필요하면 high로 설정하세요. diff 탐색·스크롤·경로 처리도 개선했습니다.
- `1.3.1` (10월 7일): 파일 간 diff 탐색·위치 표시, Windows 플러그인 관리, 하위 에이전트 오류·예약 작업 상태 표시 수정.

기존 제품 구분 `cli: 2.0`은 보존하고 바이너리 버전만 갱신합니다.

## IDE App / IDE Extensions

- IDE `2.5.5`, VS Code `1.7.0`, Visual Studio `1.0.261005.0`; 변경 없음.
- 공식 표시일에는 시각·시간대가 없으며 배포는 사용자별로 며칠 걸릴 수 있습니다.
