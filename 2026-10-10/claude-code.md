# Claude Code 변경사항

기준일: 2026-10-10 (Asia/Seoul). 이전 기록 이후 안정 릴리스 1건을 새로 확인했습니다.

## GUI App / CLI App

### 2.1.295

- 이전 기록: `2.1.294`.
- 공식 공개: 2026-10-08 19:48:38 UTC, 한국 시간 2026-10-09 04:48:38. 점검일과 출시일은 다릅니다.
- 명령·HTTP 훅에 `onFailure: "block"` 옵션을 추가했습니다. 검사 도구가 시작되지 않거나 시간 초과·예상 밖 종료가 발생하면, 작업을 그대로 통과시키지 않고 막을 수 있습니다.
- 지원 터미널에서 작업 중·입력 대기·완료 상태를 표시하고, `/copy`에서 인용문의 `>` 기호 없이 본문만 복사할 수 있습니다.
- 장시간 연결이 끊긴 MCP 서버의 재연결, 백그라운드 작업 출력과 중단·재개 처리를 개선했습니다.
- 플러그인 오류 화면에서 확인 없이 삭제되던 문제, 도구 제한 적용 누락, 긴 응답·깊은 인용문으로 터미널이 멈추던 문제를 수정했습니다.
- Claude apps gateway에는 연결 시작 제한 시간, 모델별 경로 제한, 요청 추적 기능을 보강했습니다.
- 저장소의 GUI/CLI 공통 표기를 유지합니다. 이 번호는 Claude Code 패키지 기준입니다.
