# Antigravity 변경사항

기준일: 2026-10-14 (Asia/Seoul). 이전 기록 이후 GUI `2.23.0`을 새로 확인했습니다. 공식 표시일은 2026-10-12이며, 오늘 출시된 것으로 해석하지 않습니다.

## GUI App — 2.23.0

- 입력창에서 에이전트의 권한 설정을 바로 고를 수 있습니다.
- 대화 속 이미지·영상을 전체 화면으로 열고 확대하거나 재생 속도를 바꿀 수 있습니다.
- ZIP 파일과 폴더를 프롬프트에 첨부할 수 있습니다.
- MCP 서버 시작 실패 화면에서 에이전트에게 복구를 맡기는 선택지와 재시작 메뉴가 추가됐습니다.
- 하위 에이전트가 승인을 기다리는 상태를 사이드바에서 더 분명하게 보여줍니다.
- MCP 재시작 실패, 상대 경로로 지정한 사용자 에이전트 구성 무시, 플러그인 스킬 누락 등을 수정했습니다.
- 사용자별 배포에는 며칠 걸릴 수 있습니다.

## CLI App / IDE App / IDE Extensions

- CLI 바이너리 `1.3.1` (2026-10-07), IDE `2.5.5` (2026-08-13): 변경 없음.
- VS Code `1.7.0`, Visual Studio `1.0.261005.0` (각 2026-10-05): 기존 기록 유지.
- 기존 제품 구분 `cli: 2.0`과 구성요소별 날짜를 보존합니다.
