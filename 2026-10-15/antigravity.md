# Antigravity 변경사항

기준일: 2026-10-15 (Asia/Seoul). 확인일과 공식 표시일을 구분합니다. 단계적 배포로 사용자별 도착 시점이 다를 수 있습니다.

## GUI 2.23.1 신규 확인

- 공식 표시일: 2026-10-13.
- 초기 로그인 과정에서 라이선스 목록이 창보다 길어져 아래 버튼을 가리던 오류를 수정했습니다. 긴 목록은 카드 안에서 스크롤됩니다.

## VS Code 확장 1.8.0 신규 확인

- 공식 표시일: 2026-10-12.
- 여러 대화 턴에 걸친 코드 변경 검토에서 기존 수락·거절과 수동 수정을 유지하고, 외부 디스크 변경을 감지합니다.
- 창 재시작·대화 되돌리기 시 변경 검토 복원과 사용자 수정 보존을 개선했습니다.

## Visual Studio 확장 1.0.261012.0 신규 확인

- 공식 표시일: 2026-10-12.
- 재시작 후 대화 복원, 에이전트 파일 수정 뒤 채팅 입력 초점, 여러 턴의 변경 검토 기준 유지 문제를 수정했습니다.

## 유지한 구성요소

- CLI 바이너리 `1.3.1` (2026-10-07), IDE `2.5.5` (2026-08-13).
- 기존 CLI 제품 표기 `2.0`은 별도 필드로 보존합니다. 바이너리 버전과 혼동하지 않습니다.
