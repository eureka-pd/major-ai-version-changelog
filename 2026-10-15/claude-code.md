# Claude Code 변경사항

기준일: 2026-10-15 (Asia/Seoul). 이전 기록 `2.1.296` 이후 공식 변경 로그와 최신 안정 릴리스를 대조했습니다.

## 최신 버전: 2.1.300

- GitHub 게시 시각: 2026-10-14 18:24:25 UTC / 2026-10-15 03:24:25 KST.
- 조직 제한으로 거절된 로그인 토큰이 남던 문제와 세션 재개 후 대화 일부가 유실되던 문제를 수정했습니다.
- 완료한 하위 에이전트 대화가 작업 목록에서 사라지거나, 클라우드 재시작 후 이미 답한 요청을 다시 실행하던 오류를 수정했습니다.
- MCP 재연결 중 도구 검색이 꺼지는 문제, 잘못된 MCP 입력 스키마로 매번 400 오류가 나는 문제를 개선했습니다.
- VS Code에서 사용량 소진 뒤 빠른 모드 요청이 반복 실패하던 문제와 작업 트리로 이동한 세션 복원 문제를 수정했습니다.
- 로컬 대화 기록에 API 요청의 시스템 프롬프트·도구·매개변수도 기록하도록 변경했습니다. 기록을 외부에 공유할 때 포함 내용을 확인할 필요가 있습니다.
- 기존 저장소의 GUI/CLI 공통 패키지 버전 필드를 갱신합니다. 별도 Claude Desktop 앱 전체의 버전 번호를 뜻하지 않습니다.

## 함께 새로 확인한 2.1.299

- GitHub 게시: 2026-10-14 02:49:42 UTC / 11:49:42 KST.
- 긴 대화가 유휴 상태일 때 캐시 만료 전에 압축하는 기능, 사용량 경고를 추가했습니다.
- 샌드박스 명령이 플러그인 폴더에 쓰던 문제와 헤드리스 실행이 예산·턴 한도를 넘어서 지속되던 문제를 수정했습니다.
- 공식 로그의 다음 이전 항목은 2.1.296입니다. 별도 근거가 없는 2.1.297·2.1.298의 변경사항을 추정하지 않습니다.
