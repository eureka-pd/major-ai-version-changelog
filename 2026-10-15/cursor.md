# Cursor 변경사항

기준일: 2026-10-15 (Asia/Seoul). 공식 변경 로그와 배포 관측값을 구분합니다.

## CLI 새 배포 관측

- 공식 설치 스크립트의 배포 식별자가 `2026.10.01-e373342`에서 `2026.10.14-0f9edde`로 바뀌었습니다.
- 새 식별자는 다운로드 경로와 설치 디렉터리에 표시됩니다. 스크립트를 실행하거나 프로그램을 설치하지 않고 텍스트만 확인했습니다.
- 이 빌드에 대응하는 기능·버그 수정 내역과 공식 출시 시각은 확인되지 않았습니다. 식별자에 포함된 날짜를 확정 출시일로 대입하지 않습니다.

## GUI / 공식 공지

- 공식 다운로드의 최신 GUI 배포 관측값은 `3.24`로 유지됩니다.
- 한국어 변경 로그의 최신 표시 공지는 2026-10-06 로컬 에이전트 원격 제어입니다. 이미 기록한 공지이므로 재집계하지 않습니다.
- 번호형 변경 로그 기준 `3.11`과 GUI 배포 관측값을 섞지 않고 기존 상태 구조를 유지합니다.
