# Antigravity 변경사항

- 기준일: 2026-10-17 (Asia/Seoul)
- 새로 확인한 CLI 바이너리 최신 버전: **1.3.6** (공식 날짜 2026-10-15, 이전 기록 1.3.1)
- 앱 2.23.1, IDE 2.5.5, VS Code 확장 1.8.0, Visual Studio 확장 1.0.261012.0은 기존 기록 유지

## CLI 1.3.6 핵심 변경

- 모델 연결에서 5분간 데이터가 오지 않으면 자동 취소·재시도해 끝없이 멈춰 있는 문제를 줄였다. 하위 에이전트의 질문이 사라지는 문제도 수정했다.
- Auto 모드의 샌드박스 밖 명령 검토와 민감 정보 전송 차단을 개선했고, diff 커밋 트리의 가독성을 높였다.
- Google 공식 로그는 ADC 인증에서 프로젝트가 접근 가능한 Claude Opus 5.5·Sonnet 5.5 지원을 명시한다. 이는 Antigravity의 지원 공지이며 Anthropic의 별도 출시 공지를 검증한 것은 아니다.

## 기존 기록 이후 누락분 보충

아래는 오늘 출시됐다는 뜻이 아니라 기존 1.3.1 이후의 공식 날짜별 누락 기록이다.

- 1.3.5 (10월 14일): Auto 모드, 수동 대화 압축, diff 구문 강조·접기
- 1.3.4 (10월 13일): 플러그인 목록 JSON 출력, 원격 제어 설정 동기화, 재시도 지연·OAuth 유지 개선
- 1.3.3 (10월 10일): 플러그인 하위 에이전트 지원과 macOS 앱 데이터 샌드박스 보호
- 1.3.2 (10월 8일): 플러그인 관리 화면과 diff 탐색 개선

기존 CLI 세대 표기 2.0은 보존하고 실제 바이너리 버전만 1.3.6으로 갱신했다. 공식 안내상 배포는 순차 진행된다.
