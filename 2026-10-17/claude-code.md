# Claude Code 변경사항

- 기준일: 2026-10-17 (Asia/Seoul)
- 새 버전: **2.1.301** (이전 기록 2.1.300)
- 공식 게시 시각: 2026-10-15 19:22:06 UTC / 2026-10-16 04:22:06 KST

## 핵심 변경

- 종료할 때 아직 원격에 올리지 않은 커밋이 있을 수 있는 훅 생성 worktree를 확인 없이 제거하던 문제를 수정했다. 작업 보존 측면에서 중요한 수정이다.
- 최신 Fable에 접근할 수 없는 조직에서 `fable` 또는 `best` 별칭이 실패하면 이전 Fable로 한 번 재시도한다. 이 항목만으로 특정 Fable 모델의 출시를 단정하지 않는다.
- 사용량 제한 해제까지 너무 오래 남으면 무인 재시도를 종료할 수 있는 설정이 추가됐다. 로그인 갱신과 검색 실패 표시도 개선됐다.
- 작은 컨텍스트 모델로 전환할 때 허락 없이 이전 모델로 요약 비용을 쓰거나, 게이트웨이 환경에서 반복 압축하던 문제를 수정했다.
- Vim의 괄호 이동과 여러 줄 입력 등 터미널 사용성 개선이 포함됐다.

별도의 GUI 배포 버전은 확인하지 못했으므로 기존 GUI 컴포넌트 값은 유지하고 CLI와 공식 변경 로그 버전만 갱신했다.
