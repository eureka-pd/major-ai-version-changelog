# Codex 변경사항

- 기준일: 2026-10-17 (Asia/Seoul)
- 새 CLI 버전: **0.163.0** (이전 0.162.1)
- 공식 게시 시각: 2026-10-15 21:30:38 UTC / 2026-10-16 06:30:38 KST

## 핵심 변경

- `/config`에서 설정을 검색하고 지원되는 옵션을 바로 변경할 수 있다. 재시작이 필요한 설정도 구분한다.
- 응답 도중 새 지시를 보내 즉시 방향을 바꾸며, 중단할 때 실행 중인 Code Mode와 하위 도구 호출도 함께 멈춘다.
- 저장된 대화를 다시 열 때 권한과 네트워크 승인을 복원하되 명시적 재정의와 현재 관리 정책은 존중한다. DNS 조회 전 권한 검사 등 네트워크 보호도 강화됐다.
- 독립적인 읽기 도구를 병렬 실행하고, `/daemon`에서 관리 서버를 재시작할 수 있다. Windows/WSL 붙여넣기와 명령 출력 수집 문제도 수정됐다.

## 유지된 기록

- 데스크톱 26.1007, 모바일 1.2026.272는 기존 기록과 같고 신규 출시로 재보고하지 않는다.
- 지정 공식 변경 로그는 ChatGPT Learn 통합 변경 로그로 이동한다. CLI 신규 릴리스는 OpenAI 공식 GitHub 릴리스에서 별도로 확인했다.
- 기존 모델 공지·날짜·상태는 그대로 보존했다.
