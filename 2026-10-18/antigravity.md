# Antigravity

- 확인일: 2026-10-18 (Asia/Seoul)
- 이번에 새로 기록한 버전: **앱 2.24.0 / CLI 1.4.0**
- 공식 표시 날짜: 앱 2026-10-15, CLI 2026-10-16 (정확한 시각·시간대 미표시)

## 앱 2.24.0

대화의 산출물·변경 파일·링크를 한데 모은 사이드 패널, 긴 대화를 요약하는 /compact, 자동화별 Flash Lite·Flash·Pro 모델 선택을 추가했다. 로그인 만료 안내와 권한 목록 가독성도 개선했다.

## CLI 1.4.0

지원 터미널에서 작업·입력 대기·완료·실패 상태를 표시한다. Alt+M으로 메시지 즉시 전송과 대기열 전송을 바꿔 사용할 수 있다. 플러그인 검증에 엄격 검사와 JSON 출력이 추가됐고, 시작 시 일시 오류의 재시도 및 MCP 헤더 변수 처리도 수정됐다.

이전 기록과 비교한 신규 확인이다. 오늘 출시됐다는 의미는 아니며 배포는 순차 진행될 수 있다. IDE·확장 및 다른 컴포넌트 기록은 그대로 유지했다.
