## 주요 변경

- 자동 모드의 클라이언트 측 판정 모델을 지정하는 설정과 유휴 대화 요약을 켜고 끄는 설정이 추가됐다.
- 크레딧으로만 결제되는 모델의 답변 뒤에는 후속 프롬프트 제안을 건너뛰어 불필요한 크레딧 사용을 막는다.
- 실패한 예약 실행이 한참 뒤 처음부터 재시작해 같은 보고를 두 번 게시할 수 있던 문제를 수정했다.
- MCP 호환성, 플러그인 설정 저장, 대화 압축 중 중단 오류를 수정했다. 128 MB를 넘는 이미지 입력도 거부한다.
- CLI/SDK·데스크톱·VS Code에서 fork 하위 에이전트의 기본 동작을 정리했다.

GUI의 독립 배포 버전은 이번 자료로 확인되지 않아 기존 기록을 유지했다. 소프트웨어 설치는 수행하지 않았다.
