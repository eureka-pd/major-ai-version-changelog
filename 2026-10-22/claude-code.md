## 신규 버전: 2.1.305 → 2.1.306

- 2.1.306: 클라우드 세션 안에서 `claude -p`를 실행할 때 잘못 표시되던 로그인 오류를 수정했다. MCP 도구가 많은 세션에서 실제 API 오류 대신 “프롬프트가 너무 길다”는 오류와 불필요한 대화 압축이 발생하던 문제도 고쳤다.
- 2.1.305: 일부 모델 제공업체에서 도구 검색 거절로 요청 전체가 실패하던 회귀 오류를 수정했다. 작업 폴더 선택·정리, 같은 이름의 MCP 서버 설정 충돌, 완료된 워크플로 단계가 재개 시 반복 실행되는 문제를 개선했다.
- 디스크가 꽉 찼거나 대화 압축으로 오래된 맥락이 빠졌을 때 안내가 더 명확해졌다.
- CLI와 공개 변경 로그 최신값만 2.1.306으로 갱신했다. 별도로 검증되지 않은 GUI 버전은 기존 2.1.300을 보존했다.
