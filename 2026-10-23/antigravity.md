## 새로 확인한 버전

다음은 오늘 출시됐다는 뜻이 아니라 기존 기록에 없던 공식 게시물을 오늘 처음 확인한 결과다. 게시일의 시간대·시각은 원문에 별도 표기되지 않았다.

- **앱 2.25.0** — 공식 게시일 2026-10-20. 플러그인 관리 프로젝트에 배지를 표시하고 빈 프로젝트를 숨긴다. macOS 창 닫기, 대화 검색 복구, 입력·파일 재선택 등의 오류를 수정했다.
- **VS Code 확장 1.9.0** — 2026-10-19. 코드 변경의 수락·거절 단축키, 선택형 서버 자동 복구를 추가했다. 대화 전환 시 미검토 변경을 자동 수락하거나 연결 복구 때 대화를 잃던 문제를 수정했다.
- **Visual Studio 확장 1.0.261016.0** — 2026-10-16. 프롬프트를 보낸 뒤 작업 중 상태에 멈추던 문제를 수정했다.
- CLI 바이너리 **1.4.0**, IDE **2.5.5**는 유지한다. 기존 CLI 계열 표기 2.0과 바이너리 버전은 별도로 보존했다.
