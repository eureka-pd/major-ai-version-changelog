## 신규 확인 공지: Agent SDK

공식 게시 날짜는 **2026-10-20**입니다. 이번 확인에서 직전 기록에 없던 공지를 발견한 것이며 오늘 출시됐다는 뜻은 아닙니다. 공식 한국어 페이지를 직접 재조회했으며 오래된 검색 캐시와 구분했습니다.

Agent SDK가 정식 출시됐습니다. 지침·도구·스킬·연결·채널을 프로젝트 폴더로 정의하고 로컬에서 시험한 뒤 Cursor 또는 자체 인프라에 배포할 수 있습니다. 고정 입력으로 도구 호출과 응답을 검증하는 평가, GitHub PR 이벤트 재현, PR·Slack·웹훅·일정 기반 실행을 지원한다고 설명합니다.

**의미:** 반복적인 개발 업무를 버전 관리하고 시험할 수 있는 에이전트 프로젝트로 만들 수 있습니다. 실제 배포나 연결·권한 부여는 하지 않았습니다.

앱 버전 번호가 붙은 발표가 아니므로 공식 버전 3.11, GUI 배포 관찰값 3.24, CLI 관찰값 2026.10.22-27dcf5f와 각 날짜는 유지하고 공지 상태만 추가합니다.
