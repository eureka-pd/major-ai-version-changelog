## 확인 결과
공식 GitHub 릴리스 API에서 안정판은 기존 **CLI 0.165.0**임을 재확인했다. 안정판 버전·기능을 신규로 보고하지 않는다.

새 시험판 **0.166.0-alpha.6**을 별도로 관찰했다. 발행 시각은 2026-10-29 01:41:25 UTC(10:41:25 KST)이며, 공식 릴리스 본문에는 구체적인 변경 설명이 없다. 따라서 기능이나 안정성 개선을 추정하지 않았다. 안정판 컴포넌트 값과 분리해 시험판 관찰 항목만 갱신했다.

## 확인 범위의 제한
지정된 개발자 변경 로그는 조회 도구의 4MB 응답 제한으로 본문을 읽지 못했다. RSS 대체 조회 역시 접근 승인 단계에서 차단되었다. 공식 GitHub 릴리스로 CLI만 교차 확인했으며, 앱·모바일·일반 공지 전체에 변경이 없다고 단정하지 않는다. 해당 컴포넌트·날짜·기존 공지 상태는 보존했다.
