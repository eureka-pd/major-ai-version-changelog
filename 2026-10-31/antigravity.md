## 이번 확인에서 추가한 CLI·확장 릴리스
- **CLI 1.4.10 — 2026-10-29:** 터미널 전송량을 약 70% 줄이고 시작 후 메모리 약 100MB를 반환한다고 설명한다. 대용량 이미지 자동 축소와 하위 에이전트 문맥 유지 수정도 포함한다. 성능 수치는 공식 설명이며 독립 측정 결과가 아니다.
- **VS Code 확장 1.10.0 — 2026-10-26:** 코드 줄별 댓글과 로그인 상태 표시, 백그라운드 서버 자동 복구를 추가했다.
- **Visual Studio 확장 1.0.261026.0 — 2026-10-26:** 터미널·Output 내용을 참조하고 명령을 바로 실행하지 않은 채 터미널 입력란으로 보내는 기능을 추가했다.

위 항목은 오늘 출시가 아니라 기존 기록 이후 이번에 추가 확인한 버전이다. CLI 중간 릴리스도 확인했다: 1.4.1(10/17), 1.4.2(10/18), 1.4.3(10/20), 1.4.4(10/21), 1.4.5(10/22), 1.4.6(10/23), 1.4.7(10/24), 1.4.8(10/27), 1.4.9(10/28). 최신 바이너리 값만 1.4.10으로 갱신했다.

## 유지한 상태
App 2.28.1과 IDE 2.6.0은 변경 없다. 별도 제품 표기인 CLI 2.0과 실제 CLI 바이너리 1.4.10을 혼동하지 않도록 기존 스키마를 유지했다. 설치하지 않았다.
