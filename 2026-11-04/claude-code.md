## 새 버전: 2.1.317
공식 CHANGELOG.md와 릴리스에서 2.1.317을 확인했다. 발표 시각은 2026-11-03T01:25:46Z(서울 11월 3일 10:25:46)다.

- 예약 작업을 만들 때 요청하지 않은 연결 서비스가 붙으면 경고하고 제거 방법을 안내한다. 웹·셸 도구가 계정 이메일을 외부로 보낼 때 확인하는 절차도 추가됐다.

- 일부 데스크톱 세션에서 첫 응답 후 MCP 연결이 끊기는 문제, 인증 갱신 저장 전 종료되는 문제, 재시작 시 대화가 손실되는 문제를 수정했다.
