## 이번에 추가 확인한 릴리스
### App 2.29.0 — 2026-11-03
Jupyter 노트북 뷰어와 개편된 자동화 화면, 내장 브라우저의 다운로드·방문 기록을 추가했다. Gemini Live 음성 모드와 클라우드 원격 에이전트는 순차 배포 중이다. 원격 에이전트는 Google AI Ultra·Pro 대상이며 모든 사용자에게 즉시 제공된다는 뜻은 아니다.

### CLI 1.4.12 및 1.4.11 — 2026-10-30
- **1.4.12:** API 키를 선택적으로 사용하는 플러그인을 지원하고 스트리밍 Markdown 표의 정렬을 수정했다.
- **1.4.11:** Google Cloud 로그인 후 과금 방식 선택과 실행 전 훅의 작업 종료 기능을 추가했다. JSON 출력의 비정상 종료 사유와 Claude 플러그인·원격 MCP 가져오기 처리도 개선했다.

이 날짜는 공식 발표일이며 오늘 출시가 아니라 이번에 새로 확인한 기록이다. 최신 CLI 바이너리 값은 1.4.12로 갱신했다.
