## 새 버전: 2.1.318
공식 발행 시각은 2026-11-04 00:01:03 UTC(09:01:03 KST)다. 기존 2.1.317 이후 새 버전으로 확인했다.

- macOS에서 여러 Bash 명령을 실행할 때 메모리 사용이 늘며 세션이 멈추던 문제를 수정했다.
- 업데이트나 이전 버전 정리 후 Remote Control·백그라운드 실행기가 새 세션을 시작하지 못하던 문제를 수정했다. 잠자기·일시 정지 후 원격 재연결 속도도 개선했다.
- 저장된 로그인 만료일을 인증 상태와 JSON 결과에 표시하며 비대화형 텍스트 실행은 만료 10일 전부터 경고한다.
- 잘못된 도구 호출 뒤 대화 이어하기가 이전 내용을 잃거나 유휴 요약이 요약 아닌 답변으로 대체되던 문제를 수정했다.
- 공유 네트워크 홈 디렉터리에서 설정·로그인 저장이 유실되거나 실패를 성공으로 표시하던 문제를 개선했다.
- IDE 터미널에서 시작해도 확장을 자동 설치·갱신하지 않도록 바뀌었다. 필요하면 편집기의 확장 관리 화면 등을 사용한다.

공개 CLI 버전과 발행일만 갱신했다. GUI 컴포넌트 값은 별도 배포 확인 없이 유지했으며 설치하지 않았다.
