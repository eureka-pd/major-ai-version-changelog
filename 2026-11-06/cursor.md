## 새 배포 버전 관찰
- **GUI 3.28:** 공식 다운로드 페이지의 Latest 표시를 확인했다. 기존 관찰값 3.24보다 새 버전이며, 3.25·3.26·3.27도 다운로드 목록에 있다. 각 버전의 공식 발표일과 상세 변경사항은 확인되지 않았다.
- **CLI 2026.11.05-86047df:** 공식 설치 스크립트가 지정하는 배포 버전이다. 기존 관찰값 2026.10.22-27dcf5f보다 새롭다. 버전 문자열의 날짜와 별도의 공식 발표일을 동일시하지 않았으며 안정판·시험판 구분도 명시돼 있지 않다.

두 버전은 .version의 distribution_observations에만 반영하고 발표일은 null로 유지했다. 변경 로그 기반 GUI 3.11과 CLI null, 기존 공지 상태는 보존했다. 설치 스크립트는 읽기만 했으며 실행하지 않았다.

## 변경 로그 확인 결과
영어 공식 변경 로그의 최신 공지는 여전히 **2026-10-20 Agent SDK**다. 다운로드 페이지의 릴리스 노트 링크도 일반 변경 로그로 연결되므로, 3.28이나 새 CLI의 기능 변경을 추정하지 않았다.

지정 한국어 페이지는 10월 16일 공지가 최상단이며 조회 결과가 2주 전 수집본으로 표시돼 최신성에 한계가 있다. 영어판·다운로드 페이지·설치 스크립트는 오늘 수집된 내용을 확인했다.
