## 이전 보고 이후 새로 확인한 공식 변경
아래 날짜는 공식 변경 로그의 게시일이며 오늘 출시를 뜻하지 않는다.

- **CLI 1.5.1 (2026-11-05):** ACP 클라이언트에서 계정의 사용 가능 모델을 제공한다. OAuth 토큰 보호와 Windows 비ASCII 출력·CRLF 편집, 세션 처리를 개선했다.
- **CLI 1.5.0 (2026-11-04):** ACP 서버 모드, 원격 에이전트, 로컬 프로젝트 관리와 MCP 플러그인 로그인을 추가했다.
- **VS Code 확장 1.11.0 (2026-11-02):** 터미널 컨텍스트 이동과 빠른 메뉴, 범위별 변경 승인·거절을 지원한다.
- **Visual Studio 확장 1.0.261102.0 (2026-11-02):** 인라인 diff를 기본 활성화하고 삭제 코드 강조와 읽기 전용 비교를 개선했다.

## 유지한 상태
App **2.29.0**(11월 3일), IDE **2.6.0**(10월 26일)은 동일하다. 기존 CLI 제품 표기 **2.0**을 보존하고 실제 바이너리 버전 **1.5.1**과 구분했다. 변경된 컴포넌트와 해당 게시일만 갱신했으며 설치하지 않았다.
