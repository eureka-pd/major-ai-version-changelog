공식 CHANGELOG와 GitHub 릴리스에서 **2.1.319**를 확인했다. 게시 시각은 **2026-11-06 17:04:01 UTC**, 서울 기준 **11월 7일 02:04:01**이다. .version의 날짜는 공식 게시일인 11월 6일로 기록한다.
