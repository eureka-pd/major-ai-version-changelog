## 새로 확인한 App 2.29.1
공식 게시일은 **2026-11-06**이다. 오늘 처음 기록한 항목이며 오늘 출시로 표현하지 않는다. 음성 대화의 연결과 문맥 처리를 고친 패치 업데이트다.

- 로그인을 갱신해야 할 때 연결 실패만 표시하던 문제를 고치고 다시 로그인하도록 안내한다.
- 입력한 메시지의 링크와 @멘션을 음성 모드가 인식하며, 링크만 보낸 메시지를 건너뛰지 않도록 수정했다.
- 이전 발화를 최신 발화에 잘못 붙여 응답이 막히는 문제를 수정했다.
- 통화가 잠깐 끊긴 뒤 실제 듣지 못한 답변이 기록에 표시되는 문제를 수정했다.

버전은 순차 배포되므로 모든 사용자에게 즉시 보이지 않을 수 있다.

## 유지한 컴포넌트
IDE **2.6.0**, CLI 바이너리 **1.5.1**, VS Code 확장 **1.11.0**, Visual Studio 확장 **1.0.261102.0**은 기존 기록과 같다. 기존 CLI 제품 표기 **2.0**을 바이너리 버전과 구분해 보존했다. .version에서는 App 관련 버전과 공식 게시일만 갱신하고 나머지 필드를 유지했다. 소프트웨어를 설치하지 않았다.
