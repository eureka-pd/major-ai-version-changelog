## 신규 App 2.30.0 · 2.31.0
두 버전의 공식 변경 로그 게시일은 **2026-11-09**다.
- **2.31.0**: 여러 에이전트가 협업하는 /swarm, 글자 크기 설정, 플러그인과 대화의 분할 화면을 추가했다. 브라우저 파일 다운로드는 사용자 승인 뒤 진행하며 음성 통화 요약도 제공한다.
- **2.30.0**: 조사·글쓰기용 간소화 화면과 업무별 초기 설정을 추가했다. 음성 모드와 원격 에이전트 배포도 확대됐다.

## 신규 CLI 바이너리 1.5.2 · 1.5.3
- **1.5.3** (2026-11-07): 하위 에이전트 모델 표시, 플러그인 훅 환경변수, 비 UTF-8 파일 처리와 터미널 보안을 개선했다.
- **1.5.2** (2026-11-06): 원격 세션에서 클라우드 플러그인 스킬을 지원하고 macOS 단축키·인증·권한 처리를 개선했다.

## 새 공지: Gemini 4 Carbon · /swarm 미리보기
**2026-11-10** 공식 발표. Gemini 4 Carbon은 Google AI Ultra 구독자의 App·CLI·IDE 확장에 제공되며, /swarm은 App·CLI에서 미리보기로 순차 배포된다. 병렬 에이전트 사용은 일반 대화보다 할당량을 빠르게 소모할 수 있다.

IDE **2.6.0**, CLI 제품 표기 **2.0**, VS Code 확장 **1.11.0**, Visual Studio 확장 **1.0.261102.0**과 해당 기존 날짜는 유지했다. 새 버전은 모든 사용자에게 도달하기까지 며칠 걸릴 수 있다.
