## 신규 CLI 바이너리 1.5.4 · 1.5.5
두 버전의 공식 변경 로그 게시일은 **2026-11-10**이다.

- **1.5.5**: /swarm 및 /swarm board 미리보기, ADC 인증의 Gemini 4 Carbon 지원을 추가했다. 원격 기업 모델 게이트웨이에 HTTPS를 요구하며, Claude Code 플러그인 가져오기·비대화형 실행 종료·하위 에이전트 작업복사본에 미커밋 변경 반영 문제를 수정했다.
- **1.5.4**: ACP 편집기 세션의 Auto 모드와 hook의 이벤트·작업 폴더·도구 호출 ID 전달을 추가했다. 샌드박스 외부 명령 검토 속도, ACP 권한 요청 멈춤, 하위 에이전트·원격 연결·인증 문제를 개선했다.

## 유지한 항목
App **2.31.0**, IDE **2.6.0**, CLI 제품 표기 **2.0**, VS Code 확장 **1.11.0**, Visual Studio 확장 **1.0.261102.0**과 기존 날짜는 유지했다. 실제 CLI 바이너리만 **1.5.5**로 갱신했다.

Gemini 4 Carbon 및 /swarm의 11월 10일 공지 자체는 이미 보고했으므로 별도 신규 공지로 중복 집계하지 않았다. 버전 배포는 순차 적용될 수 있다.
