## 신규 CLI 배포 관찰: 2026.11.11-043ef28
공식 설치 스크립트가 가리키는 CLI 배포 버전이 기존 **2026.11.05-86047df**에서 **2026.11.11-043ef28**로 바뀌었다. 스크립트는 읽기만 했으며 실행하거나 설치하지 않았다.

## 공식 변경 로그·GUI는 변경 없음
한국어 공식 변경 로그의 최신 공지는 기존 **2026-11-06 에이전트와 음성 채팅**이며 공식 다운로드의 GUI는 **3.29**다. 이전 기능 설명은 반복하지 않았다.

변경 로그 기반 버전 **3.11**, CLI null, GUI 배포 관찰값과 최초 관찰일, 기존 공지 상태는 보존했다. 번호 없는 공지와 실제 배포 버전은 구분한다.
