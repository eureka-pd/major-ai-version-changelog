## 새로 확인한 업데이트
- **App 2.31.1 · 2.31.2** (11월 11일): Windows의 기업 계정 로그인 문제를 수정하고 Google Cloud 기본 인증으로 로그인했을 때 Gemini 4 Carbon을 선택할 수 있게 했다.
- **CLI 1.5.6** (11월 11일): 협업 상태 화면과 Auto 모드 검사, 훅 및 게이트웨이 처리를 개선했다.
- **CLI 1.5.7** (11월 12일): 저장된 모드가 없는 세션은 지원되는 환경에서 **Auto를 기본값**으로 사용한다. strict 도구 권한은 Auto보다 우선한다. 긴 출력에 따른 멈춤과 Windows 로그인, 관리자가 강제한 승인 정책이 우회되는 문제를 수정했다.
- **VS Code 확장 1.12.0** (11월 9일): 빠른 시작과 백그라운드 업데이트 확인, 원격 로그인 처리를 개선했다.
- **Visual Studio 확장 1.0.261109.0** (11월 9일): 음성 입력과 로그인·업데이트 안정성을 개선했다.
- **Gemini 4 Hydrogen 공지** (11월 12일): 네 단계 추론 강도와 Carbon을 함께 활용하는 Orchestrator를 소개했다. 앱 버전과 모델 공지를 구분해 기록했다.

공식 게시일과 오늘의 확인일은 다르다. 배포는 순차 진행된다. 기존 IDE 2.6.0과 CLI 제품 표기 2.0 등 변경 없는 필드는 보존했다.
