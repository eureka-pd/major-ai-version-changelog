## CLI 1.5.8 (11월 13일)
- 인증 방식에 따라 Hydrogen·Carbon 모델 선택을 확장하고 전체 화면의 항목별 펼치기, ACP 대화의 컨텍스트 사용량 표시를 추가했다.
- 네트워크 경로 제한과 Windows 명령 허용 규칙, 미리 로드한 MCP 도구의 권한 규칙이 우회되던 문제를 수정했다.
- 기업용 웹 접근 경로 및 Remote Control을 제어하는 관리자 설정을 추가했다.

## IDE 2.7.0 (11월 12일)
터미널 출력을 대화에 연결하는 표시와 빠른 메뉴를 추가했다. 변경 검토 명령의 적용 범위를 명확히 하고 자동 저장 충돌, 줄바꿈 및 여러 창의 로그인 동기화 문제를 수정했다.

App 2.31.2 및 기존 확장 버전과 모델 공지는 유지했다. 날짜는 공식 게시일이며 배포는 순차 진행된다.
