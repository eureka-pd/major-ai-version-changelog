## 신규 CLI 2.1.323
GitHub 게시 시각은 **2026-11-12 22:12:13 UTC**다.
- JavaScript로 도구를 호출하는 **Code Mode**가 실험적 선택 기능으로 추가됐다. 기본 활성화라고 해석하지 않는다.
- 플러그인이 요구하는 Claude Code 버전 범위를 검사하고 TypeScript 훅 검증을 강화했다.
- 긴 훅 실행의 진행 신호와 DOCX 업로드 지원을 추가했다.
- 대화 압축·재개 과정에서 메시지가 잘못 합쳐지거나 누락되는 문제와 설정 덮어쓰기, 큰 파일 편집의 메모리 문제를 수정했다.

GUI 2.1.300은 별도 버전이므로 유지했다.
