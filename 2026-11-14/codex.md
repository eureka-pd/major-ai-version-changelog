## 신규 안정판 CLI 0.168.0 · 0.169.0
두 버전 모두 11월 13일 UTC에 게시됐다. 0.168.0은 03:54:29, 0.169.0은 08:37:05다.
- **0.168.0**: 모델 제공자 선택 화면과 선택형 터미널 분할 대화, 음성 파일 첨부 및 선택형 GIF 생성 기능을 추가했다. 저장된 제공자 유지와 실행 중 지시 전달을 개선했다.
- **0.169.0**: 선택형 터미널 작업공간의 여러 보조 대화 탭과 이전 작업 검색, 완료된 활동 접기를 지원한다. 터미널에서 사용자 지정 제공자를 편집할 수 있으며 선택형 Cloud 연결도 확장됐다.
- 신뢰하지 않는 폴더에서 프로젝트 설정·MCP 서버가 실행되는 문제와 승인된 계획 전달, Windows 샌드박스 및 중단 처리를 수정했다.
