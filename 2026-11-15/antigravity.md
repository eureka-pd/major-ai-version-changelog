# Antigravity
- 기준일: 2026-11-15 (Asia/Seoul)
- 새 앱 버전: **2.32.0** (공식 표시일 2026-11-13, 이전 2.31.2)

## 핵심 변경
- Dynamic Workflows를 추가해 내장 Python 환경에서 병렬 하위 에이전트와 여러 단계 작업을 조율할 수 있게 했다.
- Everforest 테마와 프롬프트 이동 단축키를 추가했다.
- 에이전트 제어 브라우저의 교차 사이트 프레임 노출을 제한하고 차단된 다운로드 상태를 명확히 표시한다.
- 긴 대화 스크롤과 한·중·일 글꼴 표시 등의 문제를 수정했다.

CLI 1.5.8, IDE 2.7.0 및 기존 확장·모델 공지 기록은 변경 없이 유지했다. 점진 배포이므로 사용자별 도달 시점은 다를 수 있다.
