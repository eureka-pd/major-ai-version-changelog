## 핵심 변경
- zstd 압축 응답 해제 과정의 보안 문제와 Bash·MCP 권한 검사 및 샌드박스 보호 관련 결함을 수정했다.
- 비정상 종료 뒤 대화를 재개할 때 최근 메시지가 사라지는 문제와 하위 에이전트의 모델·문맥 크기 처리를 수정했다.
- 백그라운드 세션이 의도하지 않은 API 키로 과금되는 문제, 로그인·MCP 재연결 문제를 수정했다.
- Code Mode의 작업 폴더·권한 응답·재개 동작을 보완했다.

GUI 기존 기록은 유지했다. 설치나 업데이트는 실행하지 않았다.
