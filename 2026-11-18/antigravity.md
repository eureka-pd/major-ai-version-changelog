# Antigravity
- 기준일: 2026-11-18 (Asia/Seoul)
- 아래 버전은 이번에 공식 변경 로그에서 새로 확인했다. 공식 표시일은 확인일과 다르며 배포는 순차적으로 진행된다.

## App 2.32.1 (11월 13일자)
- Google Cloud의 Application Default Credentials로 로그인하면 모델 선택기에서 Gemini 4 Hydrogen을 저·중·고 추론 단계로 선택할 수 있다.

## CLI 1.5.9 (11월 14일자)
- 내장 Python에서 여러 하위 에이전트에 병렬 또는 단계별로 작업을 나누는 `run_workflow` 도구를 추가했다.
- 관리자가 플러그인 또는 마켓플레이스를 제한할 수 있게 했다. Auto 모드 검토와 `/resume`을 개선했다.
- HTTP MCP 서버에서 다른 호스트로 리디렉션될 때 API 키 등 사용자 지정 헤더가 전달될 수 있던 문제와 Windows 예약 작업에서 여러 줄 프롬프트가 잘리던 문제를 수정했다.
- IDE **2.7.0**과 기존 확장·모델 공지 기록은 유지했다.
