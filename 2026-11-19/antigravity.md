# Antigravity
- 기준일: 2026-11-19 (Asia/Seoul)

## 앱 2.33.0 (공식 표시일 11월 17일)
- SSH로 64비트 Linux 호스트에 연결해 프로젝트와 에이전트, 터미널을 원격에서 실행할 수 있다.
- 대화의 GitHub PR 링크에 현재 상태를 표시하고 Overview에 PR 목록을 추가했다. 내장 브라우저에는 페이지 내 찾기를 넣었다. 배포는 순차적이다.

## CLI 1.5.10 · 1.5.11
- **1.5.10**: GitHub 게시 표시 11월 17일 05:41 UTC / 14:41 KST. Gemini Enterprise와 Google Cloud 기본 인증에서 두 기반 모델을 모두 선택할 수 있으면 Carbon이 계획하고 Hydrogen이 실행하는 Orchestrator를 지원한다. 원격 작업의 수정 승인 모드를 추가했다.
- **1.5.11**: GitHub 게시 표시 11월 18일 06:51 UTC / 15:51 KST. 설치 전 플러그인 ZIP이나 GitHub 저장소를 검사할 수 있다. Remote Control에서 하위 에이전트를 대화에 참조하는 기능을 추가하고 첨부 업로드를 개선했다.
- 통합 변경 로그의 CLI 항목은 아직 1.5.9로 표시되지만 공식 CLI GitHub 릴리스에는 두 신규 버전이 있다. IDE 및 확장 버전 기록은 유지했다.
