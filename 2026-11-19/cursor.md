# Cursor
- 기준일: 2026-11-19 (Asia/Seoul)

## CLI 2026.11.17-f532c45
- 공식 설치 스크립트의 배포 버전이 바뀌었다. Cursor 문서는 해당 날짜의 릴리스 변경 사항을 11월 17일자 **v2026.11.17**에 공개했다.
- 팀 대시보드에서 관리자가 설정한 프롬프트 훅이 CLI에서도 실행된다. Linux에서 CLI가 보유한 자격 증명을 다른 프로세스가 읽지 못하도록 기본 보호를 강화했다.
- MCP 리소스를 파일로 내려받을 때도 일반 파일 수정과 같은 권한 규칙을 적용한다. 자체 호스팅 워커가 워커 장비에서 실행 중인 로컬 MCP 서버를 사용할 수 있다.
- 데스크톱 다운로드의 **3.30**과 한국어 주요 변경 로그의 최신 공지(11월 6일)는 그대로다.
