# Antigravity
- 기준일: 2026-11-20 (Asia/Seoul)

## CLI 1.5.12
- Remote Control의 브라우저 화면에서 여러 대화를 나란히 열 수 있다. 휴대전화는 지원하지 않는다.
- Gemini API 키로 접속한 CLI에서 Gemini 4 Neon을 선택할 수 있다. 대화에 큰 작업 파일이 있어도 `/fork`가 그 파일을 모두 복사하지 않아 더 빨라졌다.

## Gemini 4 Neon 및 확장
- 11월 18일자 모델 공지에 따르면 지원 요금제에서 Neon을 쓸 수 있고 모델을 따로 고르지 않았다면 Neon이 기본이다. Orchestrator (Neon)는 Neon으로 계획하고 Hydrogen으로 구현한다. 앱 2.33.0과 IDE 2.7.0의 버전 기록은 유지했다.
- 뒤늦게 확인한 11월 16일자 확장: VS Code 1.13.0은 단축키 구성 선택·음성 받아쓰기·파일 첨부 동작을 추가했다. Visual Studio 1.0.261116.0은 채팅의 음성 받아쓰기를 추가하고 인라인 변경 거절 오류를 고쳤다.
