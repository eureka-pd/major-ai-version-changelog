# Antigravity
- 기준일: 2026-11-22 (Asia/Seoul)
- 앱 **2.34.0** (공식 표기 11월 20일): MCP Apps를 지원하고 Gemini 4 Neon 및 Orchestrator 이용 범위를 넓혔다. 터미널에서 선택한 출력으로 바로 후속 질문을 할 수 있다.
- IDE **2.8.0** (공식 표기 11월 19일): 백그라운드 업데이트 확인과 원격 로그인 시 자동 포트 포워딩을 추가했다.
- CLI 바이너리 **1.5.14** (11월 21일 16:57 KST): 원격 에이전트에 계획 모드를 추가했다. 로컬 세션에서는 Orchestrator의 계획 모델과 실행 모델, 각 추론 강도를 따로 고를 수 있다. 스웜 보드에 작업 진행 현황을 표시한다.
- CLI Auto 모드는 이제 기본적으로 작업공간 밖 파일을 읽을 때 승인을 요청하지 않는다. 쓰기·편집 승인과 기존 권한 규칙 및 조직 정책은 유지된다.
