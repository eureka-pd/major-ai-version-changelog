# Cursor
- 기준일: 2026-11-26 (Asia/Seoul)
- **데스크톱 3.31 → 3.32**. 공식 다운로드 페이지에 최신으로 표시된다. 정확한 게시일이나 3.32에 대응하는 변경 내역은 확인하지 못했다.
- **SDK 1.5.0**은 공식 릴리스 노트의 11월 24일자 항목이다. TypeScript·Python에서 로컬이나 클라우드 명령의 표준 출력과 오류를 실행 도중 받을 수 있다. 실패하거나 취소한 실행도 이미 끝난 모델 호출의 사용량을 남긴다.
- CLI 공식 설치 스크립트가 가리키는 **2026.11.22-e9042b2** 배포 빌드는 유지. 스크립트는 실행하지 않았다.
