# Antigravity
- 기준일: 2026-11-27 (Asia/Seoul)
- **앱 2.35.1 → 2.35.2**. 공식 변경 로그의 11월 25일자 항목이다. 응답 생성 중에도 모델 선택기가 잠기지 않아 후속 메시지나 `/btw` 질문을 보내기 전에 모델을 바꿀 수 있다. 변경 적용 시점은 화면 안내에 표시된다.
- **CLI 바이너리 1.5.17 → 1.5.18**. 공식 GitHub의 11월 26일자 릴리스다. 파일 URI도 실제 경로로 확인한 뒤 파일 권한 및 승인 규칙을 적용한다. 손상되거나 저장이 덜 된 이미지를 첨부하지 않게 했으며 Windows에서 작업 공간과 설정이 다른 드라이브에 있을 때 플러그인이 로드되지 않던 문제를 고쳤다.
- Remote Control의 코드 복사에서 빈 줄을 보존하고 하위 에이전트 답변의 수식 표시를 고쳤다. 별도 **IDE 2.8.0** 유지.
