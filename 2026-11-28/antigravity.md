# Antigravity
- 기준일: 2026-11-28 (Asia/Seoul)
- **앱 2.35.2 → 2.36.0**. 공식 변경 로그 11월 27일자. 최대화한 사이드 패널 안에서 진행 상태와 읽지 않은 답변을 보고 후속 메시지를 쓰는 입력창을 추가했다. 인계 전에 끝난 음성 통화의 맥락은 로컬 대화에 남는다.
- Auto 모드는 현재 프로젝트 밖의 다른 버전 관리 저장소에서 안전하다고 판단한 편집과 기존 파일을 덮어쓰지 않는 추가 작업을 자동 승인할 수 있다. 프로젝트 밖 변경을 따로 검토해야 하는 작업은 승인 범위를 확인할 필요가 있다.
- Orchestrator 계획·실행 모델에 같은 모델을 지정하면 다른 기본 모델로 돌아가던 오류를 수정했다. 이제 선택한 모델로 단일 에이전트가 실행된다. 내장 브라우저에서 로컬 HTTP 주소가 HTTPS로 바뀌던 문제도 수정했다.
- 별도 **IDE 2.8.0**, GitHub 기준 **CLI 바이너리 1.5.18** 유지. 앱은 점진 배포되므로 기기 설치 버전과 다를 수 있다.
